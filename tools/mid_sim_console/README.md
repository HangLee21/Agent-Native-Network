# 五板拓扑工作台

双击START_SIM_CONSOLE.cmd，或打开 http://127.0.0.1:8767/ 。已有服务时只打开页面。默认读取H006历史实测快照的20个方向，A→C、单向、不限跳数。图上可改源/目的、选择跳数、编辑方向边，运行和结果均在同页。恢复实测默认只恢复草稿，不改变物理设备。实测成功率、服务观测与未测时延的模型值分别注明来源。

“开始模拟”才启动真实固定/自适应配对计算，草稿修改与恢复默认不运行。每次冻结设置、新run ID和新目录；旧结果绑定其自身配置，当前草稿不改旧结果。“取消”终止本次计算，保留部分文件，不自动重跑。后台仅请求驱动的本机服务，每次最多一个计算，最多120秒墙时，数学库最多2线程。关闭终端时取消仍在计算的任务。

新模式比较固定初始链与时延感知简单路径。每个包锁定完整计划链；表更新只影响后续新包。候选预览描述假设拓扑，实际路线取逐节点接收事件；结果包含节点、模拟时刻和交付状态。原MID模式仍使用原SOCP执行器和设置schema。

新产物位于simulation/outputs/E2-022/<run-id>/：settings.json/options.json/scenario.json、experiment下事件与结果、stdout/stderr、job.json及RUN_MANIFEST.json。历史E2-020/E2-021结果和访问地址保留，registry沿用.local/mid/E2-020/state.json。实测基线由H measured.py编译，直接交E1 workbench执行器；原routing及MID schema入口保留。使用既有E1-016虚拟环境，不安装全局包。

同页实板状态、预览、显式发送、读取和停止经受限代理交8766原服务。边屏蔽是路由约束；时延、成功率和时间窗修改只在仿真执行，实板预览会说明限制。只有显式发送调用实板run，原服务仍检查板卡、占用与清理状态。8766未运行时说明不可用，不自动启动或发送。

API见WORKBENCH_CONTRACT.md；原routing见ROUTING_CONTRACT.md，原MID见CONTRACT.md。只监听127.0.0.1，校验Host/Origin和JSON，无任意地址或底层命令代理。未完成、失败或取消记录保留其状态。
