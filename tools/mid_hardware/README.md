# H-005 工具

`check_host.py --output <全新目录>`：编译显示模型和 fake backend，执行有限主机检查；每个子命令 120 秒上限，单并发，工作目录就是全新输出目录。不会操作串口或生成 RF 数据。

`check_connected.py`：一次枚举和已绑定 A 的旧 ANN info 核查；必须给 bindings、预期旧 build_id 和全新输出目录。只打开 USB/MAC 绑定候选的指定口，不扫描其他串口，不复位、不刷写、不启动无线。它不是 MID 新 CLI 的通用采集器；MID 工具等 E1/E2 冻结接口后再接入。allow_probe=false 不构成后台运行授权，本工具仅按明确任务执行。

`check_target_objects.py`：尝试用保留的 E1/H-004 编译参数对显示组件做 ESP32-S3 对象编译，不改旧构建、SDK、源码，不链接最终应用。本轮该分支发生 WinError623，未生成对象，已停止；不要把脚本存在当成目标构建通过。

所有路径使用 H-005 新 run，保留初始失败。后续串口/烧录/RF 必须满足 H-005 主卡依赖，不能从这些准备工具自动继续。
