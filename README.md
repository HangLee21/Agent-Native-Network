# 设备安装与启动

这是现场测试包，LoRa 下行控制当前关闭。

使用前，请给网关和设备接通电源，将网关连接到电脑，并用 USB 线连接需要更新的设备。

1. **更新设备：**双击 `FLASH_NODES.cmd`，等待窗口显示各设备的处理结果。设备会按已登记的身份识别，无需选择串口；请在操作期间保持连接。
2. **查看网络：**双击 `START_STUDIO.cmd`，等待页面打开。页面会显示设备编号和连接状态；如果网关或设备尚未连接，页面会显示对应状态。

查看结果时，以窗口中每台设备的成功或失败提示及页面实际状态为准。操作未完成或连接中断时，按屏幕提示重新接好电源和连接线，然后再次双击对应入口。运行记录位于本目录下的 `data/logs/`。
