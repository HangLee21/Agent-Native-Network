# 网关与设备使用

这是现场测试包，LoRa 下行控制当前关闭。网关初始化脚本与换电脑连接流程尚未完成实机验收。

## 首次使用：初始化网关

仅需在网关上初始化一次。将电脑与网关用专用网线直连，给网关通电，双击 `SETUP_GATEWAY.cmd`。看到电脑网口后，确认网线直连网关且未接入共享网络，按回车开始；只有检测到多个可能网口时才需要选择。若提示输入密码，输入时屏幕不会显示字符，输完按回车。等待窗口显示处理结果。初始化会配置网关直连地址、专用网口的自动分配地址服务和本机接收服务；不要在校园网或共享局域网上启用此设置。操作前请确认这是用于直连电脑的专用网口。初始化脚本仅在用户实际运行并确认后执行。

交付包自带网关所需的私有运行环境，无需联网下载，也不会安装或升级网关系统软件包。程序会先检查网关系统环境和磁盘空间，通过后自动安装；如果检查失败，请把窗口所示的诊断日志路径交给技术支持。通常只需输入一次网关密码；如果管理员密码不同，程序会再次询问。输入的密码不会显示或保存。此流程尚未在目标网关上完成安装验证。

需要回滚网关初始化时，在该文件夹打开命令提示符，执行 `SETUP_GATEWAY.cmd --rollback`，并按窗口提示操作。

## 日常使用：换电脑也一样

1. 给网关和设备通电，用网线将电脑直接连接到已初始化的网关；电脑的以太网地址使用自动获取。
2. 双击 `START_STUDIO.cmd`，等待页面打开。系统自动寻找并核对网关身份；若暂时连不上，页面仍可打开并显示离线，连接恢复后继续读取。

页面中的网关连接状态不等于设备已上报；节点是否在线以实际报告为准。若连接长时间未恢复，重新接好网线或设备电源，再双击同一入口。运行记录位于 `data/logs/`。

如需更新设备，按窗口提示使用 `FLASH_NODES.cmd`；不要在更新过程中拔线。当前仅提供脚本和离线验证，尚不能把网关初始化、换电脑连接或无线收报说成已在现场通过。

页面中“超时未见”表示节点超过上报期限未见新报告，“观测中断”表示接收入口暂不可用；两者都不直接证明设备已断电。灰色连线表示历史观测，不能当作当前连通。
