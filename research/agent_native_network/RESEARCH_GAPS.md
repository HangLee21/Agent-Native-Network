## 3. 研究假设及证伪路径

所有假设均为本项目提出的待验证问题，排序表示测量优先级，不代表已经选定唯一论文方向。

| 假设 | 先例与具体证据边界 | 可证伪实验 | 创新风险 / 难度 |
|---|---|---|---|
| H1：依赖与版本信息在相同 QoS/龄期/队列下仍有额外预测价值 | P05 已提出标签；P15/P17 已利用时效/错误。缺少本项目业务下“条件额外价值”的证据 | 固定大小、期限、AoI、队列分布，加入真实/打乱/错误标签，比较有效交付和阻塞；若真实标签无稳定净收益则否定 | 高：可能只是 AoII 的实例；低至中 |
| H2：有界传播取消比源端 TTL 更节约多跳 airtime | P05 过时抑制、P16 时效传播；尚未核实其断续多跳撤销实现 | 比较 TTL、仅源取消、全网洪泛、本地有界 tombstone；计入控制重传。低取消率或长分区下净开销增加则限定适用域 | 中高：DTN/数据库已有类似机制；中 |
| H3：依赖阻塞反馈改善路由与队列联合决策 | P01 拓扑联合、P21 队列；P06 有等待释放负载。现有两者不等于已验证的依赖感知多跳策略 | 对比最短路、ETX、Backpressure、EDF及相同元数据增强基线；若只靠期限即可取得同等效果则否定 | 高：可能归约为截止时间路由；高 |
| H4：慢推理—中速路由—快速 MAC 的分离控制产生净协同增益 | P01/P05 有多层架构，缺少本项目局部状态与开销约束下的闭环结果 | 网络侧 N、Agent反馈 A 的 2×2 消融；统一信息预算，测交互项、延迟、控制占比；若协同不超过最佳单侧则否定 | 高：跨层本身不新；高 |
| H5：阶段/依赖状态帮助 OFDMA 分配，但增益仅在拥塞与准确标签下存在 | P02 保护、P05 loop-aware radio 已覆盖方向 | 同一 AP域对比 RR、PF、EDF、AoI/AoII、队列MaxWeight；标签年龄与误差扫参；若收益来自更多总资源则无效 | 高：调度特征增量可能很小；高 |
| H6：按消息存活时间约束缓存/中继移动能改善分区恢复 | P16 时效、P05 移动连续性；多跳缓存/移动组合待查 DTN 先例 | 外生轨迹先比存储携带转发、周期复制，再加入移动中继；扣除移动能耗与任务偏离，若净收益消失则否定 | 高：既有DTN覆盖多；很高 |

H1 首先检验信息是否有价值，H2 检验能否转成协议收益，H3–H6 检验跨层耦合。H1 被否定时，应保留普通 QoS/时效机制并重评其他假设，不能强行用复杂模型维持选题。

## 4. 判别场景与必要负对照

静态地图交换、无取消且低负载的消息流是负对照：预计普通可靠传输已足够。高频观测更新可能适合 latest-only/AoI，只有同一观测对应不同依赖分支时才可能需要额外结构。长分区场景中，再准确的语义标签也不能创造物理容量，应比较本地自主降级与延迟交付。

例如两条消息生成时间相同、长度相同、截止期相同，一条解除三台节点的等待，另一条属于已撤销分支。若网络仅使用前述 QoS 无法区分，依赖标签可能有价值；但网络获取标签和传播取消也需要 airtime。其**净**收益必须连同误判成本一起计量。

公平比较时所有算法共享可取得的元数据；另设剥夺元数据实验衡量信息贡献。集中 oracle 只能作为上界，不可与局部控制算法混为同等基线。固定轨迹回放用于隔离网络因素，真实闭环用于检查到达反馈改变未来需求，两种结果分别报告。

## 5. 统一系统候选而非单层收敛

接口定义对象 → 控制面传播局部状态 → 生命周期减少失效占用 → 路由选择服务路径 → MAC/PHY实际服务 → 到达/消费反馈更新请求。各模块共享 request/epoch/version，不要求共享完整模型状态。

保留三个整体验证配置：竞争式 Mesh 基线、弱中心 OFDMA 簇加多跳骨干、后续可编程无线实验。只有当模块交互产生超过单模块增益且开销可接受时，才主张跨层协同。若各模块可独立获得同等收益，应如实采用更简单实现。
