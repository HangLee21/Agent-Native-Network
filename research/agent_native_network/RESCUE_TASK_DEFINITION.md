# 救灾候选任务：受限连通搜索中的发现回报

2026-10-21。当前活动方向；找矿覆盖策略暂停结论保留。本轮完成任务接口核查、两轮合成实验和既有策略反证，尚未进入新算法/理论阶段。

## 问题与任务边界

目标是让自主搜索机器人发现的有效目标信息在任务进行中送达接收者，并量化为回报而绕行/部署中继造成的搜索机会损失。报告内容为目标标识、类别、位置、时间及可选证据；首轮完美检测和定位只是隔离通信因果的控制，不是部署能力声明。

已有[NIST建筑传播与机器人测试证据](RESCUE_TASK_SCREENING.md)支持通信限制真实性。[SubT官方API](https://github.com/osrf/subt/wiki/API)区分传感器接口与目标类型/位置报告，报告发送仍受通信约束并有确认机制；因此不能把任务消息必然设为整幅图像。[官方通信模型说明](https://github.com/osrf/subt/wiki/Communication-Model-Tutorial)使用拓扑/距离启发式和可部署中继，并明确不高保真模拟材料损耗等传播现象。本轮读取文档而非执行SubT，模型实现是独立简化先导。

当前只做“发现→接收”，没有擅自扩展成伤员生存率、消防指挥或双机器人互相确认。机器人失联继续自主搜索，已有合理分区；没有强迫等待另一端。人类/指挥接收端的存在与机器人间去中心化转发是两个不同架构层面。

## 先导结果如何约束选题

[首轮5184次执行](../../simulation/results/2026-10-21-rescue-reporting-v1/INTERPRETATION.md)显示摘要优先基本解决合成负载下的摘要积压，但不能跨越物理上不存在的连接；返回和中继改善运行中回报又消耗搜索资源。[周期补查5184次](../../simulation/results/2026-10-21-rescue-return-v1/INTERPRETATION.md)含1728条复现，并将开发/留出种子分离；没有发现一个返回周期普遍占优。

这支持下一轮验证的候选问题：**在有限作业时间与中继预算下，什么时候继续搜索、什么时候恢复通信，才能以可接受的搜索损失尽早交付有效发现？** 这是已有多机器人通信感知规划领域的问题定义，不能仅凭它宣布创新。P29 ACHORD等已经有通信感知移动与中继，必须纳入强对照。

## 下一阶段与停止门槛

1. 引入公开建筑/城市搜索拓扑及有来源的通信配置；区分公开基准参数与实测火场分布。先验证拓扑文件/许可/版本和模型可复现性，不要求先大规模实地测试。
2. 保留摘要充分和全连通负例；检查现有事件触发返回、最近可达点同步、移动中继、机会携带与固定部署在相同时间/设备预算下能否消除差距。避免只对FIFO和随意周期比较。
3. 在拓扑更丰富的环境中分别报告发现数、有效回报曲线、截断延迟、搜索里程和中继开销；依据任务需求确定主要评价口径，不凭单一AUC排序宣称救援改善。
4. 只有接收的报告确实需要触发他端行动时才加入核查协作，并使用同任务执行器隔离通信变化。若紧凑消息与已有方法足够，则不立新的消息协议课题。
5. Agent特有需求另证：端侧推理是否改变必要消息内容、交互顺序或行动选择，目前均未测。无此证据时按普通机器人通信问题推进，不把LLM装入闭环制造复杂度。

任务级仿真可继续承担问题筛选；当前没有安装Gazebo/ns-3，也没有火势/烟流/热风险或无线协议性能结论。

## 公开拓扑阶段更新（2026-10-21）

已完成以上第1项的拓扑引入及第2项中的年龄触发、数量触发和最近可达点对照：[12672次结果](../../simulation/results/2026-10-21-rescue-graph-v1/INTERPRETATION.md)。固定上游版本、许可和哈希可复现，全部8图纳入。不是完整SubT仿真；移动时间与覆盖阈值仍合成。40项检查通过。

32个有限覆盖条件中，开发集选定既有策略在留出集较机会携带改善24个、退化2个、相同6个；27个条件发现数减少。数量触发在26个条件被选中。全覆盖全部策略严格相同。任务立足点进一步收窄为接触恢复与搜索进度的资源取舍；不能把“返回基地”这个弱对手的差距当创新空间。下一阶段检验更强路径/中继和真实报告决策用途，暂不建立新理论模型。

## 2026-10-22：由发现回报推进到辅助观测任务

当前主任务为**受限连通条件下空地协同勘察的辅助观测交付与接触恢复**。依据埃森火灾后部署中无人机外部视角辅助UGV、Wi-Fi中断影响操作辅助功能的现场记录，明确“观测产生—信息传输—接收者判断—动作执行”的任务链。完整出处、相邻任务和实施顺序见[现场证据与问题收敛](RESCUE_OPERATIONAL_EVIDENCE.md)。

下一轮将观测可视图和无线可达图分开；执行节点可本地执行、请求观测或采用保守方式，观测节点可移动补充视角或恢复接触。任务完成时间与完成量为主要指标，接触恢复开销和信息缺口用于解释结果。现有8图实验作为搜索/移动/交付模块的回归依据。
