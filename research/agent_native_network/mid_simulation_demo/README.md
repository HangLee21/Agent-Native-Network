可以切场景/种子/策略/方向、播放/暂停、拖模拟时钟或选源包。无线图随H场景假设变化，鼠标停在有向边可看PDR和载荷服务率。逐板表版本、实际安装时间和500ms周期保持的下一跳按原事件显示，配置发布不会被当成全网同时安装。绿色轨迹来自实际模拟rx事件；链路服务阶段成功但尚未收到的跳不会提前画成完成。失败尝试与终止原因另列，源包原ID、payload标记和原始文件行号均保留。时间游标会跟随该方向最新生成包；手选包会跳至它的生成时刻。

每个场景/种子/方向有固定与重规划的每秒有效吞吐叠图，灰色斜线为H真值中无正概率/正容量快照路径的区间。只有partition_restore的[20,40)双向分区；另外两场景始终有替代路。可达性只是事后解释，不传给策略，也不表示足够容量或每包必达。丢失原因与生成/终止时可达性直接使用E2交叉统计；有路但丢包没有统一归因为路由过期。

恢复使用E2预定的“事前10个1秒窗均值80%，连续3窗”的结果。分区场景从40秒重连锚点计算，另保留从20秒影响开始的总经历时间。界面区分“已恢复”“未恢复（右删失）”“无中断”“不可评价/未知”；本批60个运行方向的实际结果均为recovered，没有额外造出删失或无中断样本。更新数为发布次数，控制字节是配置帧逐有向边服务尝试的载荷字节，不含PHY开销或airtime，不把方向秒窗重复计数。
