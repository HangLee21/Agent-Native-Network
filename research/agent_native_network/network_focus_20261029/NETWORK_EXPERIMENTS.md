## 4. 强基线与归因合同

近期先比较原生AODV和OLSRv1各自完整维护行为、同一Wi-Fi DCF和有界FIFO/源pacing。路由的先天缓存与探测差异要保留并计费，不能直接强制相同控制报文数。共同总缓存上限须涵盖源、路由待发现队列和MAC队列；实现不能统一限制时逐层列出并补等总缓存敏感性，不能悄悄给某法更多内存。详细drop/queue trace和OLSR构建尚未交付，不假定已有。

| 损失指向 | 后续所需强对照 | 归因/消融 |
|---|---|---|
| 路径质量/维护 | 两类路由的合理维护参数；带损失代价时加入ETX；维护候选要对齐CTP式数据验证/滞回/自适应信标及适用Trickle构件，保留探测成本 | 同一路由只替换新增部分；默认与开发集调参版分列。固定周期→自适应间隔→有限k抑制分项消融，CTP k=∞单列；可选修复缺失不构成超越完整原协议的证据 |
| 排队/拥塞 | 有限FIFO+统一期限处理；EDF+同样缓存/期限；固定速率与合理反馈pacing，阈值/速率在开发集选 | FIFO/EDF是明确队列层的构件，不是完整协议；源排队时间计入延迟。反馈延迟、字节、CPU/状态均计费；与同字段普通规则/背压适配对照 |
| 机会接收 | 适用的ExOR类协调转发；若只借鉴某模块明确命名 | 限同频谱/射频/候选范围，协调/批处理/重复抑制完整计费；离线最优接收集仅作付费能力上界或分析，不给在线候选 |
| 短时/长期不可达 | 短期限仍保留失败；允许等待的同一业务另比有界存储转发/复制，以及MOCHA类机会交换 | 路由与DTN不是等价替代：相同期限/副本预算/存储；MOCHA通信感知移动、ACHORD中继若开放则所有方法有同权限/成本，不能让一个移动一个固定 |

基线无需机械叠加。近期诊断不是新方法胜负实验，只用两路由和合理共同FIFO/pacing即可定位；若后续声称队列新收益，必须补EDF/限速/适用背压等对照。新增语义/依赖字段同时给通用网络规则基线，真字段/打乱字段/延迟字段、去掉新增动作分别消融。若只要普通deadline/pacing就有同等收益，应将贡献表述为通用网络机制，不能另贴Agent专属标签。

所有方法固定信道数/带宽/功率/速率、射频数量、轨迹、缓存/可靠性合同、外生正文、计算预算和调参次数。MAC重试与路由重新发现是协议运行结果，不能为了“流量完全相同”关闭它们；相同外生需求不意味着每法线上字节相同。若候选改变可靠性或接入/MAC，需保留同可靠性目标对照，不能与纯UDP的弱合同比较后归功路由。

## 5. 规模、业务和计算的独立轴

记N为无线节点数、N_A为实际运行模型的端点数、S为实际业务源数。本轮W0的N_A=0；S=2不等于两个模型Agent。后续轨迹回放也不自动增加N_A，模型部署数与网络回放端点数分列。

## 6. 必须可重建的指标和损失

以统一测量窗内全部外生签发对象—目标对为分母，按唯一正文去重；预声明版本、完整性、截止及应用有效规则。网络及时有效交付不要求冒充模型实际消费；W0只标及时完整有效body。W2再分到达/实际消费，旧口径需说明从byte/s转bit/s的8倍换算，不在同图混单位。

| 主指标 | 定义及失败处理 |
|---|---|
| 及时有效交付 | p_valid=按期完整且符合冻结有效规则的对象数/全部签发数；同时列接纳分母但不能替换主分母。G_valid=8×唯一有效body字节/T，bit/s；重复收/重试/共享正文多请求不重复计goodput |
| 尾时延 | 生成到完整有效交付，包含源pacing及逐跳排队；成功子集P50/P95配全体拒绝/超期/失败/截尾。对已充分随访的固定队列给F_valid(t)=按t内有效完成数/全体签发数；失败质量不删，若完成比例不到95%则全体95%点未达到，不补成漂亮P95 |
| 单位有效服务费用 | 全节点每次PHY尝试airtime之和/有效body bit，标s/bit或ms/kbit；分逐跳、MAC重试/ACK、路由维护/ARP等互斥类别；零有效交付时报告无穷/无有效服务及原始总费用，不记0 |
| 控制成本 | 控制类别实际发射bit、airtime、报文数及状态/CPU开销；额外探测/反馈均入账。数据帧内头部已含本帧发射费，不能再当独立控制发射重复加总 |
| 恢复与连续性 | 物理事件→检测、首个可用路由、持续服务分别报；最长无有效交付间隔及未恢复比例。持续恢复预定为连续3个1Hz探测均按期到达；首次成功不等于持续恢复 |
| 空间竞争与资源 | 每节点CCA busy区间并集、尝试/重试、队列驻留/溢出、路径/控制状态；不把各节点busy相加当全网利用率，能量须有功率实测/明确模型才给J |
