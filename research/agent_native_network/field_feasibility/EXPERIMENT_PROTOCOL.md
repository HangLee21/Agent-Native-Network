# 动态三维无线电场协同采样的可行性验证

M-067，2026-11-24。此协议在正式对照结果前登记。输入版本为 Mendeley Data DOI 10.17632/bn6n2639xh.2。E2 以发布实物确定坐标、原始索引、有效值及物理时间映射。实现配置须在正式结果前单独冻结；数据或算力限制、变更及其对可比性的影响须记入结果。

## 问题与主要比较

主要问题为 D 相对 C 在相同资源下的三维场重建 RMSE 差值。分别报告机载实时可用图和离线统一融合图。前者反映信息送达价值；后者用相同重建器处理各策略全部实际采样，反映改变采样地点的价值。B 和 A 的离线融合结果应在数值精度内相同，在线图可不同。C 与 A 检验独立主动采样，D 与 C 检验分布式协调。E 给规划器全队截至当时的真实观测、位置和任务意图，作为零时延全局信息参照；启发式全局规划器没有误差最优性保证。不同策略不得读取未测真值、完整有效值图中的 RSSI 信息或未来数据来选目标。

## 阶段及试验单位

1. 查验 V2 发布清单、手册、实际 MAT，逐层/逐时核对，构建坐标访问器。对公告与文件有冲突的量注明证据；不能证明的地理朝向或哨兵语义不推断。
2. 以一个真实 V2 平面和冻结时刻做静态 pilot。连续运动、速度、机间安全距离、采样计数、无通信统计、A/B 同轨同噪声为入口自检。
3. 用相同已审计数据走完 600 s 动态过程，从数据提供的高度取样。轨迹在两个观测之间连续；若限制飞机在单层飞行须在模型中说明。安全隔离包括两个离散时刻之间的最近距离。冻结帧静态控制和动态实验必须标清。
4. 第一阶段仅依据机间几何构图，后续在相同输入上改变链路质量/带宽/时延/丢包和分区。世界读取器、通信投递器、策略与评分器角色分开。场 RSSI 不能代替机间链路 RSSI。根据阶段 pilot 诊断实现错误时，旧输出保留。物理建筑遮挡、实机链路等未提供信息单列。
5. 主对照按 N∈{5,10,20,30}、A–E、相同至少20个配对种子执行。基础 400 个策略运行；规划器开发、调参和正式评分分隔。按同种子单独比较 D 在正常/退化网络与 C 的增量；持续时间、采样数和配套控制明确。保留失败、空图和无投递情形。种子只代表初始条件/噪声等，单一城市数据不产生20个独立城市。

## 公平性与评分规则

相同节点数下，各策略共用起点、区域/高度、速度上限、采样时钟、随机噪声协议、评价格及重建参数。A/B 使用同一观测身份和噪声值。按实际记录计算移动距离和耗时；相同上限不等于相同已飞距离，必须按共同距离、时刻或样本数检查点另算或报告有多少匹配。重复测量按空间重访和同空间时间重复分别定义。避免将有信息价值的分时复测一概记为浪费。

重建基线 1/2/5/10/20% 的分母为明示空间时间评估域的可采样点，采用一致训练/留出支持；随机采样率评测与飞行任务实际可达的采样率分别报告。空间误差和随时间变化误差要给出具体计算式、支撑点及单位，避免单纯用全局 RMSE 代替两者。未来留出值仅在离线评分时读取。

对于每项配对差，报告样本单位、均值、标准差、95%区间与关键比较的配对检验；同一轨迹的体素、时间点和同一 run 的多个业务包均不当作独立种子。首要效应量为 D−C 的误差、通信字节、距离/能耗代理；B−A 为共享消融。不给通信字节、运动和 dB 误差任意拼接成总效用；有代价冲突时报告改善幅度、额外成本及收支平衡条件。无实际速率或任务 SLA 时不能宣称部署达标。

## 可验收的证据

公布可重跑入口、输入哈希、配置与种子、各阶段 manifest、每 run 指标、代表性逐消息/运动/决策轨迹、可重建的逐阶段统计，以及同一决策中去掉已到达消息后所选目标是否会改变。D 的目标必须由节点本地计算，邻机消息来自已有传输记录；只记录交换意图或离线汇总不足以支持 Q3。失联、重连、积压过期和实际运动轨迹差异都需要独立可定位的证据。按附件 Q1–Q8 明确条件与限制，负结果亦可完成可行性判断。
