# M-067 采样器与实验口径

本文描述 E1-035 的软件模拟，不是无人机飞控或可飞航线。输入是 E2 已审计的 Mendeley V2 动态 RT 场：仅查询飞机当前位置、所属高度和当前整数相对秒的值，零补点；实验中额外加入按种子、机号、时刻确定的高斯噪声。数据接口中的 0 秒对应手册第一帧，坐标是抽象 5 m 网格，最近格平局向上；原始重复极小值不作语义推断。

## 策略与可见信息

- A：每机沿预先按机号分配的竖条移动，按固定时序往返，不通信。B 使用同样的位置和噪声，也向邻居发送真实采样；通信不能改变 B 的轨迹。采样结果的离线合图应相同，在线各机可见数据可不同。
- C：仅用本机此前和当前已采观测计算主动采样候选。
- D：每机在本地使用本机观测和 D-045 网络 `poll` 实际交付的观测、摘要和意图/任务归属；没有消息或消息过期时继续本机决策。任务意图包括候选编号、高度、预测价值和 ETA，状态带高度、拥有者和有效期；只对同高度、未过期的消息作用于该层候选。每个决策保存相同实际位置和本机历史下的无消息反事实，不能把单纯发送当作收到或运动变化。摘要和状态与原始观测消息均有编码和网络开销；摘要的 `sample_count` 为可用历史条数，局部求解最多取邻近或近期 32 个点，二者不一定相同。
- E：集中启发式规划器可用所有节点截至当时已产生的观测，并按节点次序避免同高度目标重复；这是零延迟全局信息参考，没有最优性证明，不称严格数值上界。

位置规划使用每个高度相同的 5×5 几何候选格。固定核的局部 GP 后验方差除以归一化旅行距离，作为可解释的近似价值；水平、垂直、时间尺度分别 100 m、30 m、120 s，最近历史最多 32 点。已送达的同高度有效摘要通过预测方差调整评分，低编号节点未过期意图使重复目标降权；这些都是实验启发式，不是论证最优的创新算法。评分按节点可见信息计算，不使用完整场或未来场值。网络不使用环境场 RSSI 作为链路强度。

所有策略共享起点生成规则（种子会改变起点）、节点数、时间步、速度上限、噪声协议和采样时钟。A/B 同种子逐样本相同；活动节点在每个时间步当前坐标采 1 点。移动为连续线段并计算两条同步线段最小距离：若预测低于安全间距，受影响飞机冻结该步，直到无冲突；这是实验中集中式保守几何保护，不是可部署的分布式避碰或真实建筑安全检查。由实际线段记录累加航程，不能把速度上限相同解释成已飞距离相同。

## 评估与通信

每个节点档位/种子在所有配对策略和正常/退化网络完成后，从事先几何生成的评估候选中剔除各策略整次真实采样访问的格点，再取固定数量的共同未访问点；这个筛选用的是轨迹，不读信号真值。它保留全部采样动作，但依赖整次任务的轨迹，仅供事后评分，不用于在线决策。每个策略使用相同的该组评估点和重建核。按共同模拟时刻与共同采样尝试数比较，并另外计算各策略都能达到的共同距离预算；距离评分采用不超过预算的最近实际采样时刻，保存实际距离差额与时刻，不能声称精确匹配或消除动态场中的时刻差异。

主分析保留 -240.96910013008056 dBm 原始值；另提供仅从盲点评分集合排除该精确值、训练样本和模型保持不变的敏感性结果，并记录支持点数。后者不是已确认的缺失值处理。离线 RMSE/MAE/P95 使用任务结束前真实采样，在线图按每架机该时刻可用观测独立评价；按高度分层报告离线误差。时间变化误差定义为同一评估格两时刻预测变化减真实变化的绝对值均值，单位 dB，两个检查点各只使用截至该时刻的观测。

网络参数是可重复的抽象距离门限、共享 FIFO 带宽、时延和丢包，不是物理层/MAC测量，正常、退化分别按配置记录；消息发送、在途、丢弃、拒绝和真正送达分开。网络 `update` 在离散步长之间零阶保持位置，不能代表途中连续变化的无线链路。执行器在 600 s 截止处刷新网络并统计截止前已完成、待处理状态，但截止后才可读取的消息不会反向影响已做决策。没有地面站或多跳路由对照。

每个节点档位使用 20 个共同种子，种子改变空间初始扰动和噪声，网络随机数分流；四种规模都在同一张城市的 RT 数据上，不能当成 20 个独立城市。主效应和 t 区间以种子为统计单位。`simulation/field_feasibility/` 内代码、配置、任务记录和阶段 manifest 可复验；正式输出各档带独立代码快照。候选和重建参数在正式输出前冻结，未按正式结果调参。
