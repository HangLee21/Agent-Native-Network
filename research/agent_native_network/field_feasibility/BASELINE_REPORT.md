# 传统场重建基线：Mendeley V2

## 目的和范围

本报告是E2数据和重建基线，不是多无人机策略、网络协作或论文结论。数据是官方V2射线追踪仿真；数据实物、来源哈希、轴/时间映射和特殊值见 `DATA_AUDIT.md`。运行前先完成单场景pilot（`simulation/outputs/E2-044/20261124-02-baseline-pilot/`）和常数场/边界测试；然后使用四个高度、手册第100/300/600秒三个时刻进行扩展评价。每个高度和时刻使用一个由固定种子20261124派生的随机划分，不是20次独立试验，不能据此计算可靠置信区间。

## 公平设置

空间网格250×250，共62,500格，采样率的分母固定为全部格点；1%、2%、5%、10%、20%分别为625、1250、3125、6250、12500训练点。每个高度/时刻先从随机排列取128个固定测试点，再从剩余格点依次取训练点，训练集合随预算嵌套，三个方法共用所有训练和测试样本，训练测试严格互斥。固定训练集只模拟随机点测量，不等同于连续航迹下可达采样；没有飞行距离、通信、协同控制或传感器噪声注入。

空间评价使用与目标同一时刻的训练值；时间评价使用相同训练位置在目标时刻前10秒的值，预测目标时刻的同一批互斥测试点。该时间评价是带10秒陈旧观测的空间重建，不是独立训练的时空GPR或逐秒在线跟踪。每个情形每个方法分别计算测试点绝对误差均值MAE、RMSE、95分位绝对误差P95；完整按高度、目标/训练时间、采样率拆分的360行结果见 `simulation/outputs/E2-044/20261124-03-baseline-grid/scores.csv`。

## 方法与数值

三个方法均只访问所选训练样本，以二维空间欧氏距离选择最近16个局部邻居。IDW使用距离倒数平方。普通Kriging与GPR均使用固定指数协方差 `400 exp(-d/75m)` 及对角噪声方差4 dB²，通过Cholesky求解；普通Kriging施加权重和为1，GPR使用局部样本均值作为固定先验均值，输出预测均值及潜在场方差 `400-kᵀK⁻¹k`。核参数是事先指定的运行假设，未拟合或优化；GPR方差是该模型下的条件方差，不包含局部均值估计误差，尚未作校准。所有预测、误差和方差完成有限性/非负检查；常数输入保持常数的单元测试通过。局部求解使方法可在CPU运行，但不是全局Kriging或全局GPR。

## 极小值处理的敏感性

原始值全保留是主结果。独立敏感性分析 `simulation/outputs/E2-044/20261124-04-floor-sensitivity/scores.csv` 假设将 `<=-200 dBm` 从训练值和事后评分目标中排除，**这只是显式阈值假设，不代表数据源将其定义为无效**。训练只依据训练时刻观测做筛选，离线测试点按目标真值做事后筛选；测试点从相同原始128点出发，剩余107–128点。每个方法在同一情形仍共享训练/测试点，但训练样本集和评分域与主结果不同。空间5% GPR的2m、25m平均RMSE分别约5.308、3.280 dB，原值全保留分别41.015、15.188 dB；50m、80m分别约2.024、1.933 dB。这个差别说明结论对数据处理敏感，不证明过滤正确，也不能将两种分数归因于算法改进。

## 复验与边界

- 数据读取 `simulation/field_feasibility/data_v2.py`；源文件与派生数组哈希见 `data/field_feasibility_v2/data_ready.json`。
- 数值及边界测试：`python -X utf8 simulation/field_feasibility/test_data_v2.py`。
- Pilot：`python -X utf8 simulation/field_feasibility/baseline_run.py --pilot --out <新的空输出路径>`；扩展省略 `--pilot`。脚本拒绝覆盖已有输出。
- 图表：`python -X utf8 simulation/field_feasibility/baseline_plot.py --scores <已有scores.csv> --out <新的空输出路径>`；敏感性使用 `python -X utf8 simulation/field_feasibility/baseline_sensitivity.py --out <新的空输出路径>`。均拒绝覆盖原证据。
- 不利用该结果代替后续网络消息驱动决策、20组共同随机种子、完整飞行约束和独立通信链路建模。重复极小值的物理含义和地理坐标原点仍未验证，静态2m/80m文件在V2包目录中未见。
