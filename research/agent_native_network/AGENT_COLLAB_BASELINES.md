## 首轮研究方案：立足点、层次与评价

2026-10-23，依据用户要求进一步收敛。建议题目为**面向动态具身集群扩展的协作状态更新与消息发送联合控制**。主要矛盾是获取协作决策所需状态会消耗共享无线资源；更新过少使协作依据过时，更新过多使其他必要消息等待。考察该矛盾随节点、协作关系和拓扑事件增长的变化。

研究原则更新：MOCHA、AutoCast、CoSMO等已有方法提供能力和性能参照；在其原问题与原假设下提升机制、解质量、理论性质或性能—成本折中，同样属于值得研究的贡献。基线分析同时检查原条件和扩展条件，按结果确定优化空间。

### 优化层次与具体动作

首轮实验入口为**分布式通信协议与MAC之上的发送调度，使用链路/MAC反馈**。该选择服务于初步复现和机制归因；研究范围保留MAC、PHY、路由及跨层联合优化。当前实现位置是任务应用与UDP/IP之间的协作通信层：

- 联合决定状态更新触发与消息队列服务。前者回答何时发送最新状态，后者决定状态、请求、结果之间的服务顺序和发送速率。
- 用本地任务事件、已有远端缓存、队列及实际交付反馈调整策略；旧版本覆盖仅作用于可替代状态，可靠任务事件保持其交付语义。
- 按协作关系限制传播对象作为扩展动作；第一版固定传播范围，先分离更新规则和队列服务各自的收益。

首轮对照中PHY采用共同的传播、带宽、功率与速率控制配置，MAC和路由采用共同的既有机制，以隔离协议动作的作用。源端速率/队列预算是提交给网络的业务控制量，实际服务由MAC竞争产生。初期数学模型的理想无冲突时隙用于机制检查；实验需让控制消息和数据都经过相同无线执行器。后续可研究EDCA/接入/预留、功率/编码/频谱、路由以及联合控制，各候选按性能收益、开销与可实现性比较。

### 首轮可比较的baseline集合

| 角色 | 明确采用的对照 | 比较目的 |
|---|---|---|
| 任务执行器 | 原HeteroMRTA冻结策略；原Greedy作为第二执行器 | 保持任务语义和指标，测同一网络机制是否跨任务策略有效 |
| 基本通信对照 | 调参后的周期同步＋latest-state＋统一类别队列/限速 | 得到同步频率与任务效果的基本折中；期限队列仅用于原生有期限的任务 |
| 状态更新对照 | 状态变化/年龄阈值触发＋相同队列服务 | 判断收益是否仅来自减少更新；阈值用开发集选择 |
| 直接机器人协议对照 | **MOCHA**的机会接触、头部/版本同步、主题优先级机制 | 比较已有按需交换最新信息的强方法；原系统复现与统一底层上的机制适配分别记录 |
| 任务价值发送对照 | **AutoCast**的接收者相关性与分布式发送调度 | 在原协同感知条件验证，再在具备同类信息用途的任务中做明确标注的适配 |
| 拟议方法及消融 | 更新触发与队列服务联合控制；分别只改更新、只改队列 | 测两项控制的独立作用与交互效果 |
| 诊断参考 | 同一任务执行器、同一规模的即时信息运行 | 分离任务策略本身的规模泛化与通信限制；作为参照运行而非最优解 |

**优先级：MOCHA作为直接通信协议baseline，AutoCast作为任务价值调度对照。** CoSMO用于第二批学习式更新对照，需将其控制动作和训练负载适配到共同任务；MGF/C-MASS先在各自原模型验证。ARMA/CORA继续作为接口和预算设计参考，不要求第一轮复现整套蜂窝系统。

HeteroMRTA第一轮只序列化它实际使用的任务、能力、位置与执行状态；这些流提供状态维护实验。观测数据竞争实验采用AutoCast原协同感知任务，后续再接已有救灾观测依赖流程。两类实验分别报告，保留原任务消息组成。

### 指标与判定口径

| 级别 | 指标 | 口径 |
|---|---|---|
| 主指标：任务性能 | HeteroMRTA原makespan与完成比例 | makespan为整个任务集完成时长；到实验上限仍未完成的运行同时报告完成比例/失败，避免仅比较成功样本 |
| 主指标：网络成本 | 每完成任务的空口成本；同等任务性能所需空口预算 | 分列状态、任务数据、协议开销及重传；按冲突域核算，广播一次占用与多个接收者收益分开 |
| 主指标：扩展性 | 节点数/动态强度—完成比例与makespan曲线 | 固定无线配置；预先确定完成比例及时间要求后可定义最大可支持规模；同时报告完整曲线 |
| 机制解释 | 消费时状态龄期、重复派遣/过时状态相关决策差异 | 决策差异通过相同本地决策点的及时状态参考计算；其任务后果另测，差异本身不等于错误 |
| 机制解释 | 必要信息及时交付比例、P95交付延迟、积压 | 及时性以任务的实际消费窗口定义；未交付数量单列，避免只算已交付消息 |

对全部完成的配对运行可报告 $T_{\rm network}/T_{\rm instant}$ 作为同策略的时间膨胀比；即时信息策略不是全局最优。HeteroMRTA存在必须组队才能完成的能力需求，因此不默认使用“单节点独立完成”作净收益基准。对原本支持独立执行的任务，再增加该对照。

固定总任务与固定每节点任务分别测；固定区域加密与固定密度扩区域分别测。所有通信baseline采用同样信息可得性、物理资源和调参预算；感知/推理耗时与任务策略保持一致。每个规模先运行即时信息参照，检查任务策略自身的规模效应，再归因网络机制。

| C-MASS | 二阶互补信息、Hybrid Greedy与探索/利用 | 单接收者预算到多接收者共享竞争；互补度与状态过时 | 2024作者稿核查，正式版待逐项比对；尚未定位作者代码 |
