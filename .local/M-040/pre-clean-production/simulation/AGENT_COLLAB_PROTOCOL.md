# 分布式辅助观测通信：运行前方案

2026-10-22。固定运动对应的外生链路时序，隔离通信机制；本轮执行规则智能体。两个执行节点、一个辅助观测节点、一个缓存转发节点，路径为执行端—转发端—观测端。每个节点只在完整接收消息后产生应用事件。任务位置抽象为可执行的观察工位；此轮单独验证交互与网络执行器，暂不接入上一阶段城市图。

每执行端在0/60/120/180/240/300秒产生任务。种子0–23固定任务是否受益于额外视角（概率0/0.5/1）。本地充分时10秒完成；需要额外视角时，可独立用90秒完成，或发送请求，观测服务串行耗时5秒，结果收到后10秒完成。协作等待120秒后采用90秒本地方式，已开始本地执行则不改道。任务执行槽相互独立，观测服务为共享单服务台。所有时间是机制扫描输入，当前只运行这一组成本。

消息请求160字节，结果512/65536字节；背景地图更新0/65536字节、每30秒由观测端发给两执行端。带宽1024/8192/65536字节每秒。链路全开，或每120秒开40秒（各链路相位由种子固定，跨策略共用）。三个链路共享一个总传输预算；发送端轮转、每次最多1024字节；缓存无限、逐跳完整接收后才转发、断连保留部分传输。没有丢包和ACK成本，记录的是链路应用字节。传输每跳至少一个时间步。

策略：independent（本地执行）；ideal（同观测排队与任务处理，网络即时）；fifo（缓存转发FIFO）；priority（本地队列请求/结果优先于地图，帧边界抢占）；on_demand（同priority，停止主动地图广播）。地图不参与本轮辅助任务判断，on_demand用于测量削减无关推送的收益。所有合作策略使用相同必要结果大小。
