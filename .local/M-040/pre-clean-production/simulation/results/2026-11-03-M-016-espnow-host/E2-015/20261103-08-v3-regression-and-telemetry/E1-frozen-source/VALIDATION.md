## What the same-core scenarios check

chain: five logical nodes, four hops, discovered source path and reverse endpoint ACK. ack_loss: drop first reverse ACK while link callback remains successful; two DATA attempts, one endpoint delivery, duplicate re-ACK. echo: reverse-direction echo is a new transaction with original request boot/seq in payload and correlation log, not a cross-node timestamp subtraction. state: seq2 before seq1 preserves newer value and expiry clears it. expiry: a disconnected path terminates at local source lifetime. cancel: outstanding source cancellation and destination-before-DATA tombstone. error: relay-link failure returns error and invalidates cached source route; bounded rediscovery exhausts. reboot: both source and receiver restart with new boot IDs; no claim of durable receive dedup. bounds: pending/stream capacity, oversized payload and idle submission rejection; no live seen eviction. continuous:100 sequential transactions all endpoint-confirmed, then old out-of-window seq rejected without redelivery. wire:250-byte roundtrip, CRC corruption/index/truncation rejection and5000 deterministic invalid-frame inputs. serial: identity/nonce, no-RF idle, malformed/duplicate/trailing/unknown requests, wrong binding, arm-before-bench, count cap, bounded bench, stop, null hardware fields and512-byte limit.

Assertions include many wire checks;6196+ assertions are **not** that many wireless samples or independent experiments. Scenarios are deterministic synthetic event harnesses directly executing ann.c, not a separate mock protocol. Fake link success/loss is labeled synthetic, and no delivery rates/RTTs are promoted into hardware records.
