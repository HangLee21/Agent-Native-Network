# 观测反馈机制审查与当前分支结案

2026-10-21。目的：区分“取得新数据”“数据改变下一决策”和“跨节点及时交付改善任务”三个命题，防止用任务规划差异冒充通信价值。本轮在文献核查后连续完成因果审计与空间混合检查。

## 代码审计带来的更强反证

现有规划器读取的只是测量乘以响应矩阵R所得9维值。此前无噪声构造满足remote(s)=truth(s)R；所以规划使用的测量内容作业前已经知道。真实细谱虽能改善最终重建，却不必途中发送来决定路线。

仅用初始先验预演完整事件顺序得到的静态计划，在全部72个不同无噪声设定（12种子重复后864条）复现在线路线。完整谱换为9维投影在全部1728组不改变路线或终局误差。由此将旧static的构造顺序差异与在线科学信息价值分开。见 [因果审计](../../simulation/results/2026-10-21-cuprite-feedback-audit-v1/INTERPRETATION.md)。

继续补入空间混合后运行8064条评分，保留全部布局和负例；共享可产生局部改善，但没有稳定越过所有静态和本地对照。见 [空间混合结果](../../simulation/results/2026-10-21-cuprite-spatial-mixing-v1/INTERPRETATION.md)。数据尺度和任务策略限制意味着不能否定整个真实找矿领域。

## 判定及重新进入条件

**暂停当前“低维光谱覆盖→在线网络机制”分支；停止为它扩大参数搜索、安装无线模拟器或建立网络理论。** 勘查任务、补充观测价值及既有代码保留为基线/反证资产。

重新进入任务仿真应具备以下可核查条件，而非先行设计一个想要的算法：

1. 确定实际科学输出：地表材料类别/解释置信度或可验证的连续属性；不能把未知光谱聚类自动称作矿种标签。
2. 数据支持地面观测修正事前解释：独立粗细传感器配准，或明确标为代理的数据生成与已知误差；缺少波长/物理尺度时不推断矿物吸收特征或品位。
3. 选同一任务规划器，做冻结模型/仅本地更新/全信息更新对照，隔离学习与非短视规划的作用；无反馈对照同样允许离线最终融合。
4. 先确认观测值改变行动且改善独立评价结果，再比较跨节点共享；固定核GP仅方差目标保留为不依赖观测值的负对照。
5. 若共享成立，先检验必要的紧凑信息、任务尺度截止时间和已有同步机制；剩余可归因损失才是网络理论入口。

这些条件可以先用公开数据和仿真核查，不要求先大规模实地测试。当前没有满足全部条件的新任务被宣布成立。
