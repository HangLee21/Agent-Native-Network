# 真实模型负载、动态多跳网络与跨层机制的验证方案

2026-10-27，E2-010。面向 **Scalable and Adaptive Networking for Distributed Embodied Edge Intelligence**。本轮仅完成资料核查、设计与静态检查，推理、模型/数据下载、训练和仿真均为0。以下数量均为建议下一任务卡批准的预算，不是已执行结果或自动运行授权。

## 1. 验证对象与纠偏后的判断标准

研究对象是承载独立模型设备持续变化交互的无线网络系统。需要证明网络在设备移动、加入退出、链路变化、多跳和分区条件下，能够发现服务、建立路径、承载推理生成的需求，并维持可测的服务连续性及资源效率。状态同步只是控制面中的一个模块。

旧报告把“真实模型自主生成需求”和“动态多跳网络”排在同步改进之后，容易用旧执行器能够测什么来决定研究什么。本方案将二者提升为前置证据门槛；不能以补几种同步触发器完成本轮纠偏。完整读过[用户要求](../../../coordination/handoffs/M-011-user-request.md)与[旧详细报告](../RESEARCH_PROGRESS_AND_PROBLEM_STATEMENT.md)，旧结果保留，不重算大量数据。

三链相互制约：A产生真实独立模型通信轨迹并验证证据反馈；B在成熟无线模型中验证动态性、多跳与扩展；C在相同模型计算预算和无线资源下检验具体网络机制。A通过不等于B通过，固定轨迹回放也不等于真实模型闭环。

**第一轮应回答的可证伪问题：** 在相同外部感知任务、模型调用预算与无线配置下，利用有限、付费取得的推理阶段/需求有效期信息，是否比合理调参的路由、传输和接入机制更能交付仍有用途的多跳消息？如果优势完全来自少发需求、增加算力或放松正确性，网络机制主张不成立。

### 3.2 首选输入与任务，不把数据集几何误当网络几何

首选公开 **nuScenes mini** 作为P2多视角感知核查输入：各节点仅见分配给自己的相机帧/时间窗，回答区域是否存在行人、车辆或遮挡目标等可按标注核查的问题。官方devkit提供mini目录和传感数据/标注组织，取得数据需账户及条款接受[S3]；官方索引说明数据按非商业用途提供[S4]。本轮未下载，完整现行条款正文因网页需JavaScript未读到；取得前保存当时条款、版本及数据hash，不把devkit许可等同数据许可。

该数据来自同一车载传感平台的多视角，不是多台无线机器人实测。因此：①它可证明信息隔离下的逻辑模型交互；②不证明独立车辆感知、设备运动或网络接触；③B的移动轨迹另生成并标为网络受控场景，不将车载相机外参直接当多个设备位置；④不把录制帧变成可被Agent任意改变的物理世界。首轮任务闭环指“证据→推理→请求/终止→报告”，不声称机器人动作闭环。

备选 **WILDTRACK** 的官方页面明确给出七台静态、标定同步的相机[S5]，适合核查多设备视角互补。所读页面未发现完整数据许可，不将其默认为可重分发；许可取得前不成为首轮必备依赖。它也不能证明移动摄像设备的物理反馈。若需P1行为闭环，另采至少3个实际摄像节点的受控目标核查序列，记录新增数据的许可、标注和采集范围。

只使用已按录制时间释放的帧；标注真值仅评估器可读。根问题、目标区域和评分规则在比较前冻结，不看方法结果挑选“成功案例”。初始可共同知道节点ID/声明的能力和粗略视场，动态能力/可达性更新必须付费；“全体能力目录已知”另作为宽松对照，不能在新主比较免费提供实时服务状态。

### 3.4 自主行为接口与真实性核验

运行时只提供工具语法和合法节点集合，不预写通信DAG、下一接收者或固定轮数。模型可以：`request(peer, query, modality, deadline)`、`respond(request_id, evidence_refs, body)`、`request_crop`、`revise`、`cancel`、`finish(answer, evidence_refs)`。请求目标、内容、追加和终止由当前局部输入与实际到达证据决定。执行器只核验权限、时序、预算和格式，不用真值替模型选下一动作。

所有非法输出、修复调用和工具拒绝均记账；最多一次格式修复且占同一调用预算。序列化提示、目录、发现、正文、请求、取消、可靠传输反馈均进入对应网络费用。图像按实际编码尺寸发送，文本按UTF-8字节发送；不以token数替代空口字节，不用填充字节伪装真实多模态需求。

真实性不靠“输出不同”判断。对同一决策前缀设置配对证据干预：正常按时收到、延迟到截止后、完全缺失；另用同场景合法替代视角作为有标记的反事实诊断，禁止把与当前帧不相符的伪证据当主实验。冻结模型抽样种子、前缀和图像输入，比较后续请求目标/内容/停止与最终正确性，确认差异与证据ID对应。温度0也不假定完全确定，应保存实际输出和运行时版本。不要求收集隐藏思维链，只保存对外工具决策、简短理由与可核查引用。

### 4.2 节点生存、故障与图的定义

区分三类事件：①进程/推理停止但无线仍通；②无线关闭或移动失联；③设备服务新加入/永久退出。不能只把应用停止发送称为网络退出。规划先预分配最大节点池，改变无线可用性、进程服务及发现声明分别记录；这是预创建节点的激活模拟，不冒称仿真中任意动态创建网络栈。针对OLSR限制优先用真实传播失联/恢复，接口关闭场景另测并报告实现边界；不能免费重置路由表帮助某基线。

物理图 \(G_P(t)\) 的评估边可定义为固定参考帧/配置下预测成功率超过预先设定阈值的**有向**链路；阈值、包长和采样窗口须冻结。这是离线评估定义，协议只能得到实际探测/ACK/控制报文的局部估计。单次随机丢包不等于拓扑变更。交互图 \(G_A(t)\) 按实际未终止请求的源—目标边定义，不从固定任务DAG生成；取消和截止单独终止，不删除历史需求。

记录节点活跃数、邻居度分布、连通分量、可达对比例、图直径/不可达比例、协议实际跳数分布及链路变动率。拓扑归一化变化率可记为 \(|E_P(t+\Delta)\triangle E_P(t)|/(\Delta\,\bar{|E_P|})\)，空边集时记NA并报告完全分区。协议不得读取该评估真值。

### 4.3 有界网络入口与扩展矩阵

**B1先验证机制而不追求饱和：** 4个微场景（3跳静态链、移动断路后改道、隐藏终端/并发空间复用、分区后重连并含一个服务加入/退出）×AODV/OLSR×3网络种子，共24次包级仿真。每次建议20秒预热、120秒观测、10秒有标记排空；TTL可跨排空则只跟踪至截止。业务先用小型明确标记的工程测试流验收，不称模型负载结果。

B1成功标准：路径至少2跳的实际逐跳trace存在；无路径时无瞬间交付；路由/发现/ACK/重试计费；分区存储及过期可重建；干扰微场景出现预期可区分的争用/复用。协议不能恢复也应保存未恢复结果，禁止强行把所有场景调成成功。

**B2扩展入口：** N=8/16/32/64，ρ=N/面积，采用两族：F1固定A₀增加密度；F2固定ρ₀并令面积=A₀·N/8。两族N=8共用物理基点，所以是7个不同配置×2路由×3网络种子=42次。每个配置映射同一已冻结A负载集合，不把复制相同视频块成更多节点称作新的感知多样性证据。基点A₀由开发场景使路径确有多跳后固定；功率、带宽、天线和噪声不随N调整以制造失效。B1+B2最多66次建议网络运行；Mesh、DTN、OFDMA尚不在此额度内。

这里N指全部无线节点，另记实际运行模型的节点数\(N_A\)、转发节点数及当前活跃服务数。B2首轮固定\(N_A=4\)，其余节点仅转发，证明的是给定模型业务下的网络规模，**不是64个独立模型智能体实验**。随后另立A3/B4卡，令\(N_A=4/8/16\)均运行真实独立上下文，在总计算预算固定/每节点预算固定两族中测自然生成业务；先取得足够感知输入及A真实性证据，再决定数量。扩展trace回放可用于压力诊断，但必须标为经验轨迹扩展，不能把轨迹复制当新增模型调用或独立感知设备实测。

| 待分离因素 | 第一轮控制方法 | 必须报告，不能混淆 |
|---|---|---|
| N、密度、区域、直径 | F1/F2分族；每族冻结放置和边界规则 | N与ρ有结构关联，不能宣称完全独立因子；报告实际连通/直径而非只给边长 |
| 平均跳数与空间复用 | 受控近/远通信对分层，使用同一无线配置 | 端到端流与逐跳流量、并发成功发射及干扰区；不能把全网总吞吐锁成单链路速率 |
| 移动与拓扑变化 | B2先固定一种冻结轨迹；之后固定N=16比较静止/慢/快轨迹和一次分区 | 速度、实际链路寿命、断路次数分别报告，非只给随机游走参数 |

B2不做所有变量笛卡尔积。建议B3在N=16上对“3移动档×2总/每节点负载族×2路由×3种子”另立36次卡；模态和加入退出另立卡，不能自动加进66次。若原生负载始终轻，应报告服务可行区并检查动态控制/路径维护的代价；不先降带宽再将拥塞当自然结论。高需求场景只能来自有来源的多模态任务或明确标记的压力测试。

### 4.4 实机与仿真的边界

P1最低验证为至少3台真实设备形成经trace确认的2跳路径，分别记录本地推理和真实无线交付；单机network namespace只能作为协议原型。抓包/转发日志须确认路径，不用应用日志推断无线已发。首先验证单射频/可控路由；OFDMA/RU、逐帧MCS或功率控制只有在驱动/固件暴露对应接口后才能声称实机可执行，否则保留为仿真，或另立SDR原型卡。不是要求一次将全部层部署到同一普通网卡。

## 5. C链：配对控制与跨层候选的最小证伪

### 5.1 共同业务回放与真实闭环

- **同业务回放：** 固定A导出的请求、正文、源、目标、发布时间和截止；各网络方法服务同一清单。网络发现、路由、反馈仍各自实际生成并全部计费。固定回放估计网络交付差异，不能证明模型会因此改变行为；网络失败后也不能删除原请求。
- **真实模型闭环：** 每次模型调用只见本地与实际已交付证据，网络到达改变后续请求/终止。共同根问题、时间释放的感知输入、模型权重和预算；消息清单可以不同，必须同时报告生成量、未生成需求的根任务后果及计算消耗。
- **校准后的事件驱动联合执行：** 网络虚拟时钟与推理完成时钟统一，不能在回放中以零时间产生推理输出。首轮可由P2实测条件化推理时延驱动离线联合调度，标为“实测时延驱动仿真”；P1才给实时间性能。闭环不能只播放一次冻结消息后声称反馈存在。

### 5.2 因子与公平性

主消融采用2×2：传统/候选网络机制N₀/N₁ × 固定/可适应Agent通信行为A₀/A₁；四格共享相同初始场景和外部根目标。在固定回放中只做N对照；A变化不能仍声称同一业务清单。对结果Y报告网络效应及交互项：\((Y_{11}-Y_{01})-(Y_{10}-Y_{00})\)，不把所有联合差值都记为网络收益。

固定每回合总模型调用数、输入图像/上下文token上限、输出token、推理硬件时间配额与线程/并发；实际使用量另报。N扩展分别做总计算预算固定、每节点预算固定两族；后者计算资源随N增加，应明示。请求负载同样做固定总量与固定每节点量；不能同时增加模型/频谱/任务资源却只用N解释结果。

配置选择先按开发场景给各方法最多6个完整参数配置，各配置相同网络种子集合、墙时和推理额度。参数选择规则为预先冻结的完成约束下网络代价，不能测试后为本方法换目标。慢控制（秒级服务/协作者）、中控制（毫秒至秒级路由/队列）、快控制（帧级MAC/PHY）先按实现能力设范围，不把LLM推理放进每个slot。对反馈周期做同等3档敏感性，测滞后、振荡、控制流量和CPU；调参开销与推理费用全部保存。

合理周期维护、按需路由、拥塞限速/队列调度、store-carry-forward等是强基础能力。无Agent信息、只有网络本地状态的同结构规则必须存在；免费真实消费者、未来接触、真实丢包原因只能作为有标记的离线诊断上界。同步恢复模块的收益要在这些基线之外检验。

## 6. 统一度量合同

观察区间为\([0,T]\)，根任务集合\(R_0\)在比较前固定。Agent实际签发的子请求集合记\(R\)，每请求有产生时间\(a_r\)、截止\(d_r\)、源/目标、有效正文、取消原因及根任务ID。\(R\)允许随闭环变化，\(R_0\)不能由被测方法缩小。正文到达与消费不同，准确但未消费、过期或不再需要的传输均分别保留。

| 指标 | 精确定义与单位 | 分母及防止假提升 |
|---|---|---|
| 端到端吞吐 | 完整交付的去重应用payload bit / T；按对象—目标接收者对去重；重复和重传不重复计入 | bit/s；广播多接收者计数另列，主跨方法对照先用单播。逐跳MAC成功payload bit/s另列，不能混作端到端吞吐 |
| 有效goodput | 上述去重正文中，在截止前、内容校验有效且满足已登记请求的bit / T | 不以模型自报“有用”计分；明确区分有效到达goodput与实际消费goodput。错误答案不能靠更多token提高值 |
| 请求交付率/多跳交付率 | 截止前完整有效交付请求数 / 全部已签发请求数；多跳组按冻结拓扑分层的源—目标请求定义 | 已取消、过期仍留在全部分母并单列；不能按实际成功路由跳数筛选掉无路请求。实际逐跳路径另报 |
| 尾延迟 | 请求签发至完整有效正文到达的端到端时延；分排队/路径发现/发送/推理服务/返回 | p50/p95/p99以明确成功子集给出，并列全请求截止达标率与删失曲线；零交付则分位数NA，不能记0。p99样本不足时只给经验值和数量 |
| 控制面成本 | 邻居、路由、能力发现、接口声明/反馈、取消、ACK、探测等互斥类别的每跳每次实际TX bit/空口秒/能量 | 链路重试全计，广播发射一次计一次；接收能耗另列。网络总空口=正文+控制+重试等互斥项，不将同一ACK算两遍 |
| 频谱效率 | 聚合端到端有效goodput / 实际占用频谱总带宽 | bit/s/Hz；同频空间复用使全网值可超过单链路值，不解释为单链路物理效率；另报除以区域面积的效率密度及节点数/信道数 |
| 空间复用与信道占用 | 各时刻同时成功传输对数及位置/干扰关系；按节点/区域记录CCA busy和各发送区间 | 不用全网发射时长简单相加充当单一信道busy并集。OFDMA分别记录PPDU空口和RU×时间资源，不把并行RU重复计成PPDU时间 |
| 网络重构时间 | 外生断链/加入/退出时刻到受影响请求对恢复连续K=3个1Hz探测成功且延迟达预定门限的首时刻 | 探测计费且所有方法相同；60秒观察上限未恢复记右删失/未恢复，不能删除。路由表收敛与业务恢复分别记 |
| 服务连续性 | 固定观测窗内，外部预定需要服务的时间bin中达成截止交付的bin比例，并报最长中断 | 无业务bin不自动算成功；所有方法共享计费探测可补测。分区时间纳入总体结果，可另报条件可达结果但不可替代总体 |
| 任务成功 | 在外部截止前满足冻结标注/评分要求的根任务数 / 全部根任务数 | 错误、拒绝、预算停止、超时均留分母；不能取消困难根任务。未安全执行物理动作时只能称感知/报告成功 |
| 计算/能量 | 各节点prefill/decode、图像预处理、排队、模型调用、token、GPU/CPU时间、显存与可测能量 | 计算与空口分别计量；没有功率传感器不估成实测焦耳，不给毫秒与字节直接相加 |
| 规模边界 | 满足预设任务成功、请求截止、控制预算与队列稳定约束的配置集合\(\mathcal F\) | 参数含N、ρ、区域、跳数、移动/变化率、负载、模态、计算与频谱；不是单个“最大N”。只报告已测边界/删失，未失败不等于无限可扩展 |

取消需分“根任务已正确完成后的冗余请求撤销”“新证据使子请求无需求”“过载丢弃/拒绝”“超过预算被迫停止”。所有已发费用保留。主请求交付率仍用全部签发集合，合法冗余取消可能降低该比率，因此必须与根任务成功/成本联合解释；可以附加有效需求子集指标，但不能用后者替代总分母。未签发子请求无法从日志计数，所以用固定根任务、共同可用信息和任务正确性约束防止压抑需求假获益。

探索性服务可行域可写为：\(\mathcal F=\{\theta:P(S_{root})\ge s_0,\;P(L_r\le d_r-a_r)\ge q_0,\;C_{ctrl}\le c_0,\;Q\text{无持续增长}\}\)。阈值由应用需求和开发阶段固定；例如0.9/0.95等都不得未经需求依据写成普适标准。有限运行的“队列无持续增长”仅能以末段斜率、区间和剩余积压诊断，不能证明长期随机稳定性；存在自然负结果时保留，不反向改变阈值。

## 7. 统计、失败与运行来源

初始A/B/C仅用于机制入口和反例。正式比较建议至少30个独立场景/拓扑块，每块3个网络随机种子；同一录制scene的多个相邻窗是簇内重复，不作为独立scene。正式数量还需按开发集效应、目标精度与算力预算另卡冻结；nuScenes mini不足以提供30个独立scene，须扩充合规数据或收缩泛化主张，不把六相机/多帧乘成30个独立样本。

配对单位为相同外部场景、放置/移动、感知输入与模型配置；网络seed在块内重复。对独立场景/拓扑块的配对效应给95%簇bootstrap区间（建议2000重采样），保留块内MAC/衰落重复；如独立场景数过少，报告全部配对点及范围，不给虚假精确区间。多个移动场景套在同一感知scene上时用多层/两因素分组汇总，不能把它们视作完全独立任务证据。尾延迟先每块计算/汇总，不能对所有包独立bootstrap证明任务泛化。

根任务成功率按全部分配回合；非预期崩溃、OOM、工具格式失败、墙时/事件/模型额度停止和网络不达逐类记录。某方法崩溃不删除对应配对；保留完整分配表，成功条件时间只作附表。网络和模型随机流分开固定；方法改变事件数时同seed不保证相同随机路径，因果诊断需固定前缀/外生轨迹而非只比seed。主比较预先1项，其余探索与多重比较明确区分。

每次运行沿用[公共manifest](../../../coordination/templates/RUN_MANIFEST.json)，公共来源字段必须存在，专用字段扩展而不改历史manifest。新增数据、权重和源码revision/hash、提示词/图像变换hash、硬件档、部署P级别、随机流、时钟映射、调参分配、退出码和未完成请求均保存。输出仅落`simulation/outputs/<新任务ID>/<run-id>/`且入口拒绝覆盖。当前E2-010不创建这些目录、不准备环境。

未发生字段用null/缺省规则，不用0伪装未测时延。身份、对象、请求和packet/hop关联允许重建完整多跳与重传费用；私有收件箱之外不得通过共享日志向模型提供其他节点内容。
