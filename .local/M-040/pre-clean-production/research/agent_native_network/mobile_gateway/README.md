# AD-HOC 动态组网与业务观测

正常入口是 [8794 动态现场页面](http://127.0.0.1:8794/map/)。打开即持续读取实际节点，默认现场模式、GPS 关闭。双击 `deploy/mobile_gateway/START_ADHOC_STUDIO.cmd`，或按 H 的 `deploy/mobile_gateway/STUDIO.md` 启动。页面不再依赖 8767 台架图。

## 页面操作

页面会分别提示“正在连接”“上游业务服务未连接”“在线但尚无板子报告”“已有板子但缺少 RF 邻居样本”，并给出下一步。上游未连接时可用统一启动器恢复服务；已有图形会标为上次记录。服务恢复后自动更新，保留布局、筛选和关注的包，不会自动转入软件演示。

- **现场网络**：节点、板内 agent 运行状态与计数、原包 TX/RX 来自实际无线维护查询和报告。热点 IP 入口单独标注。没有邻居报告就显示“尚无板间邻居样本”，不会从热点关联或源目的地址画 RF 边。
- **软件演示**：先切到软件演示，再点“启动 fake_agent 演示”。控制器启动隔离的 E2 node、fake_agent、fake_GPS 进程和 host_model 传输。节点按演示过程陆续加入，随后有确认、断连、重入和网关重连。每轮最长120秒；“重新演示”启动新会话，“停止演示”结束该轮软件进程。来源始终标为模拟，不算实板 RF 验证。
- **模拟 GPS 位置层**：显式勾选才叠加展示坐标。现场的板内 agent 和真实 RF 记录不随坐标运动改变。关闭后保留实际节点，改用无距离含义的动态拓扑。
- **自动布局 / 动态拓扑 / GPS 地图**：自动模式在有未定位节点时使用关系布局；GPS 地图只绘有效位置。拓扑按任意节点和实际报告的关系排版，没有固定五角星。GPS 地图保留当前位置、平移、缩放、等米制比例与可选联网底图；所有模式均不绘运动历史尾迹。
- **Agent 与逐包记录**：每条包按 origin/boot/seq/dst 保留。点记录会关闭“跟随新包”，便于核对文本和原始 HEX。TX 本跳提交、RELAY 本地收、RX 目的收分别显示。蓝色包段只来自具体下一跳/上一跳字段；紫色虚线只是选路向量。缺少逐跳字段时只显示原事件，不补完整路径。“重看记录动画”只重放保存的观察，不发送新包，也不表示无线时延。
- **持续观测**：页面可见时每2秒读取；暂停、隐藏或离开后停止相应读取和动画。演示进程由控制器显式停止或在120秒限时结束，关闭页面不停止真实板内业务。

现场默认没有真实 GPS。早期D028曾看到5个节点而没有RF邻居样本；M033现已接入真实邻居报告和即时查询，只有当前双方启动身份与年龄界限均成立时才显示绿色双向线。颜色会随证据刷新、过期而改变。RAM覆盖与抽样跳过单列，不能据页面记录数计算完整交付率。

静态文件为 `index.html`、`map.css`、`map.js`、`view.js`、`studio-model.js`、`studio.js`，全部本地加载，无打包/CDN依赖。控制接口见 [STUDIO_UI_CONTRACT.md](STUDIO_UI_CONTRACT.md)。旧8790/8791没有studio API时，仍能读各自现场状态；演示按钮禁用，页头提供8794入口。PC业务主动发件表单尚未实现，本页没有实板业务发送按钮。

## 启动

在项目根目录，用H的正式现场入口：

```powershell
python -X utf8 -m tools.mobile_gateway.live --host 127.0.0.1 --port 8790 --output ./runs/field-001 --open
```

`output`必须为新的目录。默认不扫描串口、不运行节点模型、不填预设身份，GPS默认none，也不启动业务。Ctrl+C停止本次网关。仅启动后看到空图是正常状态。

复用本机已经运行的单板服务时，先按实际端口读取`/api/edge/status`核身份，再附加观察者，例如：

```powershell
python -X utf8 -m tools.mobile_gateway.live --port 8790 --output ./runs/field-002 --attach-edge 8780 --gps none --open
```

8780是例子，须换成当前真实所有者端口；可重复`--attach-edge`。观察者经HTTP共用既有串口所有者，不能再为同一板打开第二串口。显式需要假GPS时用`--gps fake`；RF来源仍取实机字段，缺RSSI保持不可用。不要把默认无定位改成预设五边形。

各树莓派独立运行节点程序时，PC网关改为`--host 0.0.0.0`并监听同一局域网接口；Pi侧用PC的实际局域网IP：

```sh
python3 -X utf8 -m tools.mobile_node node --edge-port 8780 --gateway http://PC局域网IP:8790 --gps none --state ./runs/car-001
```

本机edge端口属于该Pi，不是PC远程串口。真实GPS提供器与随机业务的参数以`python -m tools.mobile_node node --help`和E2说明为准；只有显式启动`agent`或`--agent`才发业务。网关和地图不在业务转发链上，关闭网页不会停止板端发现或收发。

## 使用与判据

逐包行按原始 `origin / origin_boot / seq / dst` 合并，不能只凭序号或到达时间合包。当前状态分别显示：

| 状态 | 页面已有证据 |
| --- | --- |
| 仅排队，未见提交 | 源端接纳入队 |
| 已提交 / 已见中继，待目的收件 | 本跳提交、链路回调或中继本地收件 |
| 目的实收原字节 | 目的节点自己的完整身份与载荷收件 |
| 板端本轮无路 | 源端明确无路记录；stop取消另列为未知 |
| 源端拒绝 / 本地丢弃 | 源端明确拒绝或丢弃记录 |
| 最终交付未知 | 明示未知、本跳失败或中间节点丢弃，未见目的收件 |
| 目的收件字节冲突 | 同一原身份下出现不同载荷，保留冲突样本 |

异步目的收件会更新同一个包；后到的本跳失败不撤销已有目的收件。页面会提示 RAM 累计覆盖、抽样跳过、节点事件溢出和网关保留范围；缺少收件记录不能直接判丢包。每个会话保留最近128个包，每包最多48条普通观察，另保留原始收件和两种载荷样本；旧包超出保留范围时不再承诺本页持续跟踪。点包可冻结关注，并按状态筛选，详情显示最后观察者和网关收报时间。

D-029正常现场曾观察到 C→A、源boot1817436791、seq97、HEX `7061636b6574207061636b6574206e6574776f72`：23:20:17源端排队/提交，23:20:18的目的收件随后被页面自动合并为实收。这里是同一PC网关的收报时刻，不是RF传输耗时。原始身份/字节和前后DOM证据保存在D029/03-browser-input；不能据此代替完整交付率测量。

邻居线与表格均来自同一份 `state.edges`。主图每对节点只画一条线：单向单箭头，双方曾有观测才双箭头；双向新鲜互证为绿实线、曾双向但时间未知为紫虚线、单向未知为棕虚线、过期旧样本为淡灰点线。正反向中只有一边仍有观测、另一边已失效时，只画前者的单箭头；反向旧样本保留在详情。箭头露在节点圆外，近距离用外侧曲线；选节点突出相邻边，列出收到谁和谁收到我。实际线型小图例贴在图下。业务包路线默认不叠在RF图上，仅显式勾选才叠加。箭头为“发送方 → 接收报告者”，线旁标方向和样本年龄；点线或方向可看 RSSI、原始样本、观察者boot和互证字段。未知 RSSI 留空。明确lost、过期、观察者陈旧和新鲜双向互证分别显示；`sample_age_ms=null`但有`sample_age_lower_bound_ms`时显示“≥…（仅下界）”，不以它证明当前有效。显式partial报告的轮转合并由E2/H完成，页面不另补未上报的边或刷新其年龄。

- 页面打开立即读取同源`GET /api/v1/state`和`GET /api/v1/timeline?after=<cursor>`，可见时每2秒继续读取，无十分钟上限。点击“暂停现场观测”停止；隐藏时暂歇，重新可见且未被用户暂停时恢复；离开页面停止。网关不可达时明确提示并继续重连，最后快照不冒充当前状态。
- 经纬度按局部米制等比例投影，带米尺、平移、缩放及参考经纬度。null、无效、无年龄或stale定位进入“未定位 / 定位过期”，不在GPS地图上补坐标；动态拓扑只分配无地理含义的排版位置。仅作为邻居被看到、尚无自身报告的MAC也单列为未定位。
- GPS年龄、精度、来源与报告年龄分别显示。H已经给位置/样本年龄加过报告年龄，前端只补浏览器读取后的经过时间，不重复加报告年龄，也不相减两个板的单调时钟。
- RSSI方向是`peer_id → 报告节点`，两个方向分别列出RSSI、样本年龄和来源。互证采用网关`mutual_confirmed`；仅一端报告confirmed不画成双向互证。无线lost与telemetry offline分开，网关连接断开不能证明节点或无线失联。
- 时间线区分板端选路、本板SDK提交、链路回调、中继本地收到、目的本地收到、失效和重新上线。选路向量不当完整沿途实收；目的收件须有本地目的观察者、原始origin/boot/seq/dst和0–160字节payload_hex。网关会话变更重置旧快照/游标，旧session和旧seq不能覆盖新状态。事件保留有上限，截断会提示。

## 离线与联网底图

默认底图是本地米制网格，HTML/CSS/JS不从CDN加载，断互联网仍可经局域网读实际网关。需要道路底图时在“连接与底图”显式勾选OpenStreetMap；仅请求当前视域瓦片，显示贡献者署名，不预下载瓦片包。底图加载失败时保留本地网格与全部观测。在线底图遵循[OSMF瓦片使用说明](https://operations.osmfoundation.org/policies/tiles/)，地图范围会传给相应服务。

网关位于其他主机时，优先直接打开那台主机提供的页面，保持同源。页面“网关地址”可改HTTP(S)根地址，但跨源访问需要网关自身允许；这里不会绕过浏览器跨源限制。

## 验证与边界

D-027的独立模型检查和8796浏览器夹具位于`simulation/outputs/D-027/`。固定C/B/A等事件只存在于该测试输出，未包含在现场页面中；其GPS/RSSI和业务事件都是synthetic，不代表真实GPS、射频或E1算法通过。真实现场四板等结果由H-016记录，D只消费网关状态，不操作板子。命令、截图、最终文件hash及临时进程状态在D-027任务卡和交接文件回填。

即时邻居查询上线时，连接证据可按网关给出的年龄上界判断新鲜，不要求精确sample_age_ms。详情分别列最近听到/双向确认年龄上界、有效期、双方启动身份和查询时限依据；即时连接证据与旧RSSI采样保持独立。前端沿现有只读HTTP读取这些结果，不向板发送查询或业务。

M033已有真实C↔B即时上界正例：双方boot/query/RTT、seen与确认年龄在D029/13、14和最终15证据中保存。mutual_valid_for_ms减去浏览器读回后的经过时间，<=0撤绿；另有独立到期绘制计时，下一次HTTP失败也不等待旧30秒窗。隐藏/离开/用户暂停时不后台绘制，继续观察时立即按原证据已过时间更新。

组网图的“邻居来源”默认Wi-Fi，可切LoRa回传。LoRa页只展示接收器实际收到的LRN1邻居快照，紫色虚线表示采样时的Wi-Fi关系，不显示为当前新鲜绿线。上方报告列表单列报告者到接收器的LoRa RSSI/SNR、报告序号和PC收报年龄；点击方向可核采样钟、双方boot、Wi-Fi RSSI、LoRa收报钟、截断与原始记录。未收到自己的LoRa报告的邻居成员会明确标出。原agent/逐包/时间线和GPS来源保留，缺定位回退非地理拓扑。切回Wi-Fi停止LoRa请求，由H服务按空闲期限释放串口。
