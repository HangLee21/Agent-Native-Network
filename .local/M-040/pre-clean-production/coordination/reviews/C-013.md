## 方法与复查入口

本次在仓库根目录用 `.\.venv\Scripts\python.exe -B -` 接收标准库脚本，解析 JSON、求和、计算 SHA-256。复算本地文件另用：

```powershell
Get-FileHash -Algorithm SHA256 research/agent_native_network/preparation_20261028/SOURCE_LOCK.json,research/agent_native_network/preparation_20261028/SOURCES_AND_LICENSES.md
```

远端请求使用 `urllib.request.urlopen(url, timeout=25)`，单响应最多读取 2,000,001 byte，超过 2,000,000 byte 即拒绝解析。GitLab 文件 API 形态为：

```text
https://gitlab.com/api/v4/projects/nsnam%2Fns-3-dev/repository/files/<URL编码文件路径>?ref=ea50b72ab79b1ec5912c66d5b384effa829f18bc
```

JSON 的 `content` 作 Base64 解码，再对原字节使用 `hashlib.sha256(raw).hexdigest()`。普通 sandbox 请求报 WinError 10013 后，获准的 metadata-only 请求完成复核。web 工具部分固定 raw/blob URL 报 cache miss；对应关键文本改由主仓 API 或固定 resolve 文本核到。所有远端内容只在内存处理，证据摘要保存在本报告。
