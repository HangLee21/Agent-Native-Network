# 任务：纠正当前科研方向偏差，重新确立Agent-Native动态可扩展无线网络研究主线

请重新审视当前仓库的研究方向、文献调研、数学模型、实验设计和下一阶段计划，重点阅读`RESEARCH_PROGRESS_AND_PROBLEM_STATEMENT.md`及其关联资料。

**本轮任务是研究方向的实质性纠偏，需要重新评估研究问题及技术路线，而不只是调整文档措辞。**

## 一、当前研究存在的问题

最初的研究目标是构建面向具备独立端侧智能能力的设备的去中心化无线网络，研究现代端侧LLM/VLM、具身智能设备及多模态模型如何改变网络运行机制。

但当前研究逐渐收缩到了HeteroMRTA任务执行、状态同步、版本恢复以及对象—消费者关系维护。

这些工作已有一定实验依据，但存在明显不足：

1. **缺乏网络动态性研究。** 当前实验主要使用固定节点、单竞争域、简化无线配置，没有充分涉及设备加入退出、移动拓扑、多跳路由、链路变化、网络分区与重构。
2. **缺乏真正的网络可扩展性研究。** 9/18/36节点实验主要反映任务执行规模和应用消息量，尚未系统研究节点规模、节点密度、网络直径、拓扑变化速度和无线资源竞争如何共同影响系统能力。
3. **端侧智能程度不足。** 当前采用冻结HeteroMRTA策略，任务和能力预先给定，没有真正引入LLM/VLM自主推理、动态信息需求、多模态模型输出及推理驱动的设备间交互。
4. **网络研究深度不足。** 当前重点是状态同步费用，对动态路由、MAC竞争、OFDMA资源、PHY链路自适应及跨层控制缺乏充分探索。
5. **研究定位偏传统。** 如果最终只是优化异构多机器人状态同步、任务维护和恢复协议，与已有机器人协作及分布式状态管理研究容易重合，也无法充分体现端侧智能和具身智能技术发展的新特征。

尤其需要重视：目前无线实验中的信道busy比例很低，尚未观察到严重的网络容量瓶颈。不能据此假设大规模网络已经拥塞，也不能直接把现有状态同步结果推广到动态、多跳、高密度无线环境。

## 二、重新确立总体研究方向

建议将长期研究方向调整为：

**Scalable and Adaptive Networking for Distributed Embodied Edge Intelligence**

面向分布式具身边缘智能的动态可扩展无线网络。

核心研究假设：

网络由大量具备独立端侧模型推理能力的异构设备组成，例如无人机、机器狗、手机、机器人及工业边缘节点。

每个设备可以运行LLM、VLM、小型多模态模型或专用智能模型，能够独立感知、推理、产生通信需求并执行行动。

设备之间通过动态、去中心化或弱中心的无线网络协作，允许D2D、多跳、局部连接、移动拓扑和间歇连接。

**论文的研究主体必须是网络系统本身。**

需要研究的是：当网络节点具备自主推理能力，且设备、物理拓扑、通信需求和模型能力持续变化时，现有网络协议及资源控制机制面临什么新问题，以及如何设计更高效、可靠、可扩展的网络系统。

研究范围不能提前被限制为路由或MAC中的单一问题。允许构建包含控制面、网络层、传输层、MAC/PHY和拓扑控制的完整跨层系统。

同时也不能为了追求完整性而简单叠加已有算法。需要识别贯穿不同层次的统一网络机制。

## 三、重新组织核心科学与技术问题

请围绕以下五个方面开展研究。

### 1. 动态网络形成与演化

研究设备移动、加入退出、失效、无线链路变化和网络分区时，自组织网络如何发现邻居、维护可达性、重构路由和恢复服务。

重点考察网络重构速度、拓扑维护开销和业务连续性。

分析传统MANET、Mesh、DTN、机会网络和机器人自组织网络已有机制，明确端侧智能设备带来了哪些额外要求。

### 2. Agent推理与网络通信需求的共同演化

研究端侧模型如何产生新的通信行为：

- 自主生成跨设备信息请求。
- 根据推理结果动态改变通信对象。
- 产生不同模态和数据规模的业务。
- 根据收到的证据改变后续推理及传输需求。
- 自主终止、追加或重新组织通信交互。
- 因模型能力不同而动态选择协作对象。

要研究智能体逻辑交互网络与实际无线物理网络之间的动态关系。

可以采用两个共同演化的图：

\[
G_P(t)=(V(t),E_P(t))
\]

表示物理通信拓扑；

\[
G_A(t)=(V(t),E_A(t))
\]

表示智能体之间的信息需求和交互关系。

重点研究两个图如何相互影响，以及网络如何以有限维护开销承载持续变化的智能体交互。

双图本身只是一种分析工具，不应直接声明为创新。

### 3. 网络可扩展性

将可扩展性提升为核心研究指标，而非实验附属内容。

至少分别研究：

- 节点规模N。
- 节点密度。
- 网络区域与直径。
- 平均多跳路径长度。
- 拓扑变化速率。
- 智能体交互请求强度。
- 多模态数据流规模。
- 网络控制面状态与通信开销。
- 空间复用、干扰和无线资源竞争。

分别设计固定面积增加密度，以及固定密度扩大区域的实验。

研究网络性能随规模增长的变化规律、稳定服务范围和失效边界。

不得仅根据任务完成时间随节点数增长而改善，就得出网络具有良好可扩展性的结论。

### 4. 跨层网络控制

重新审视网络控制面、路由、传输、MAC、PHY和拓扑调整的关联。

重点探索：

- 推理状态能否辅助动态路由或传输控制？
- 网络负载能否反过来约束智能体通信和推理行为？
- 动态交互关系能否辅助局部网络资源管理？
- 推理阶段变化是否带来可预测的无线竞争模式？
- OFDMA资源、功率和MCS能否利用任务通信需求作出有效调整？
- 移动智能设备能否在感知任务与网络连接维护之间自主调整角色？
- 不同控制时间尺度怎样协调？

需要明确每一层能够获得的状态、控制变量以及真实硬件可执行性。

普通Wi-Fi硬件对OFDMA资源控制可能存在限制，应区分协议原型、网络仿真和SDR验证。

### 5. 新型智能体网络协议架构

研究是否需要设计Agent-Network Interface，使端侧模型和网络协议栈能够双向交换必要的状态与控制信息。

例如模型能力、当前通信需求、依赖关系、消息有效期、邻居可达性、拥塞程度及预计传输时延。

分析这些信息如何被取得、压缩和维护，以及额外开销是否值得。

此前的选择性同步、关系维护与版本恢复可以保留为动态网络控制面的一个模块，但不能预先指定它是最终唯一的核心创新。

现有HeteroMRTA、MOCHA、Latest、FIFO、因果任务执行和009无线实验都有价值，应保留为历史证据、传统业务基线及协议功能回归入口。

1. 已经证明的状态维护和任务执行现象。
2. 尚未验证的端侧模型智能行为。
3. 尚未实现的动态多跳无线网络。
4. 尚未开展的规模扩展实验。
5. 尚未得到实证支持的跨层优化假设。

尤其不要继续将冻结HeteroMRTA作为具备LLM/VLM自主推理能力的主要证明。

应尽快规划引入真实端侧模型，让模型能够基于感知结果自主生成通信需求，并将这些真实交互轨迹接入动态网络实验。

## 六、重新规划下一阶段实验

建议建立三条相互关联的验证链。

**A. 真实智能体通信负载**

运行多个独立LLM/VLM实例，测量真实模型产生的消息、交互拓扑、依赖关系、推理时延、消息大小和需求变化。

**B. 动态无线网络**

支持动态节点、移动、无线衰落、干扰、多跳、网络分区、路由维护和空间复用。

使用成熟网络模型和合理的协议基线，明确区分仿真与实机证据。

**C. 可扩展跨层控制**

在A和B的基础上研究是否需要新的网络控制机制。

比较传统网络方法与利用Agent运行状态的跨层方案，验证在不同规模、密度、移动性和业务负载下是否真正具有收益。

主要指标包括吞吐量、有效Goodput、尾延迟、网络控制开销、频谱效率、多跳交付率、网络重构时间、服务连续性、任务成功率及规模边界。

实验必须能够区分：性能改善究竟来自网络机制、应用行为、节点增多还是计算资源变化。
