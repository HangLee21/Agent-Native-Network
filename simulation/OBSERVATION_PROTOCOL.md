# Cuprite 单节点观测价值检查：运行前固定方案

2026-10-20。本方案在首轮 Cuprite 结果运行前写入，后续更改须另存实验版本。目标仅为检验新增高光谱观测代理的作用，不比较网络方案。

## 数据来源与质量处理

数据来自 [Settembre 等论文](https://doi.org/10.1186/s40323-025-00313-6) Data availability 明确链接的 [作者仓库](https://github.com/gaetanosettembre/data_unmixing)，固定提交 `29774c39f00d385b1d7898a8b1f26b3710aa036b`。下载脚本固定文件 SHA256；原始 MAT、README、LICENSE 仅存本地忽略目录 data/cuprite，不再分发。

仓库采用 GPL-3.0，README 声明基准用于研究与教育并须遵守原始数据条款；不能将该说明扩展为我们已取得所有下游用途许可。

MAT 中 Y 实际为 188×47500，nRow=250、nCol=190，与 README 的 250×191 不一致，以文件字段为准。SlectBands 保存原始波段索引；原始索引 3 的 6724 个值超过 10000，集中在 65486–65534，其他波段无此现象。本轮删除整个该波段，不擅自把 uint16 转为有符号负值。保留 187 波段。

文件未提供可靠的反射率缩放、中心波长和地理配准信息。因此逐像元做 L2 归一化，只研究光谱形状，不把数值当作物理反射率。按 MATLAB 列优先惯例恢复二维数组；方向与空间定位尚未独立验证，不用于真实路径/距离结论。

## 与文献的关系

[P31 原文](https://ojs.aaai.org/index.php/AAAI/article/view/9673/9532) 使用航空光谱代理近距离测量，配合另一传感器的低维数据，并用线性混合重建检验采样光谱库。本轮沿用“低维观测 + 实测代理库 + 非负线性拟合”的基本构件，**不复现其 ASTER 配准、MESMA、路径规划或完整实验**。

将187维归一化光谱按索引分为9组并取均值，得到人工低维遥感观测；这不是 ASTER 的真实响应函数，也没有模拟无人机专用光谱仪。采样时获得原187维航空光谱的代理测量。目标是检查光谱维度互补，尚未模拟空间分辨率差异。

## 固定划分与方法

- 开发区：行0–79、列0–79；用于固定4个初始校准光谱，按低维空间最远点选择。
- 评价区 A/B/C：起点分别为(行0,列100)、(90,0)、(170,100)，各80×80，互不重叠。
- 每区256个规则网格候选采样点；另从非候选点固定抽取256个评价像元。任何策略不读取评价高维光谱，只有评分函数使用它。
- 额外测量数：0、4、8、16、32。比较随机、空间覆盖、低维光谱覆盖三种固定规则；后两者使用最远点选择，无新优化算法。
- 三种观测条件：无噪声高维代理、标准差0.002的噪声高维代理、只用原低维信息重建的控制组。控制组在相同采样点增加相同数量的光谱库列，排除单纯扩大库容量造成的假收益。
- 用 SciPy NNLS 根据评价点的9维观测拟合非负系数，再用所采集187维光谱重建；**不使用评价高维真值求系数**。不额外拟合丰度和为1约束，不作矿物丰度结论。
- 12个随机种子控制随机采样与代理噪声。确定性无噪声方案在种子间重复，不能把重复视作独立样区；每区分别报告，不给伪独立显著性。

本轮预算仅为测量次数，不包含旅行与采样时间。主指标为留出归一化光谱 RMSE；同时报告相对初始校准库的变化。数值不可直接与上一轮合成数据的反射率域 RMSE 比较。

不预设必须有正向结果。若代理观测有效，只能进入路径预算和采样基线验证；不能直接推出在线共享收益或无线瓶颈。若无效，保留结果并检查信息互补假设和估计方法。

