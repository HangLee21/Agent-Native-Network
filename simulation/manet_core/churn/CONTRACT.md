# Controlled host restart comparison

The version-2 and version-3 snapshots receive the same synthetic RF and workload. A configured source reboot destroys its RAM state, cancels its in-flight radio transmission and queued frames, resets local business sequence, changes its boot epoch by +40, and preserves external traffic RNG. Other nodes retain local route state. The environment logs `reboot`; old boot frames in transit from other senders can still arrive. v3 requires monotonic epoch and has no authentication. This is a simulation variant, not a physical reset, and the exact handling of pending SDK callbacks is an explicit approximation. Origin ID+boot+sequence identity and right-censoring are essential. Before using reboot results, compare v2 no-reboot event stream against the matching baseline.
