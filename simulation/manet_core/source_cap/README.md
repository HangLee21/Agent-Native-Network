# Pressure-adaptive source request cap, exploratory

Same bitmap+adaptive source as `../bitmap`. Policy 45 combines policy13 with an origin-only cap of three RREQs per second when locally received duplicate pressure in the preceding second is high; otherwise the original ten/s cap applies. Discoveries deferred by rate cap retain their pending business entries and bounded timeouts. Pressure goes inactive if no RREQ has been seen for at least two seconds. This is a deliberately testable parameter hypothesis, not a proven controller or faithful paper implementation. Fixed windows and pending limit may create unfairness/rejections or repeated attempts, and must be measured. The five-seed paired comparison must hold the same source, schedule, source limits and per-packet offered inputs.
