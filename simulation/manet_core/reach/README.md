# Submit-time shortest-path instrumentation

This isolated diagnostic version computes shortest hop count from the current synthetic geometric adjacency solely for the event log; it never passes the graph or future positions to nodes. None means the geometry graph was disconnected at submission. It does not establish sustained connectivity, real RF reception, or a unique reason for an undelivered message. Compare event streams and outcome summaries against the uninstrumented version on identical inputs before using results; run against a new output scope.
