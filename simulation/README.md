## 任务与对照

两个节点、12×12 格点、16 维光谱；各节点在预先划定的半区内采样，避免通过故意重复访问制造通信价值。四分之一格点固定留出，禁止近距离采样。初始遥感先验仍覆盖这些位置；隐藏的是细光谱代理真值。

| 条件 | 决策与通信 |
|---|---|
| static | 仅用初始先验共同离线规划，以预计观测填充计划中的光谱库；执行中不改计划 |
| local | 根据自身实际观测更新光谱库并重新选择目标 |
| ideal | 与 local 相同规则，另接收即时传来的对端观测 |
| good | 同一规则；1 Mbit/s、20 ms、持续可用 |
| intermittent | 同一规则；9.6 kbit/s、200 ms，每 30 s 可用 10 s |
| stress | 同一规则；512 bit/s、1 s，每 60 s 可用 5 s |
| disconnected | 不交付消息；须与 local 完全一致 |

所有速率、中断、时间、噪声和速度均为**未经现场校准的探索性参数**，不是从论文提取的设备值。每节点预算 120 s，速度 1 格/s，测量 4 s，决策 0.25 s；不模拟返航、障碍和电池。格点尚未映射为实地米数。

strong_prior：原分辨率加 0.01 标准差噪声；coarse_prior：3×3 均值降质加 0.02 噪声。地面代理测量噪声为 0.01。两类先验使用同一配对种子的隐藏场景。另有无噪声完美先验单元检查。

决策采用“到已知光谱库的最小均方距离 / 行动时间”的固定贪心规则。它是可检查的任务执行器，不是 P31 的复现，也不是新算法；静态方案虽使用科学信息并预先分工，仍未证明达到强文献基线水平。尚未进行参数搜索，不据此主张算法优越性。

每次消息携带观测编号、生产节点、位置索引、生成时间、波段数和 float32 光谱：默认共 88 字节。双方共享地图，故位置索引可解码为坐标；校准与定位误差当前省略。共享串行服务队列支持断连后续传，并记录真实序列化的应用字节。没有 MAC 竞争、协议头、ACK、丢包、路由、运动相关覆盖或多跳。

该网络是理想化可靠字节服务，不是 MOCHA/ACHORD 复现或足以证明新调度机制的强基线。队列机制与传播时延均用 SimPy 时间推进；截止时仍在传输或传播的消息不再交付。节点不等待对端，可以继续工作。

## 评价口径与公平性

主指标：固定留出格点的细光谱预测 RMSE，反射率值域 [0,1]。固定估计器用初始先验与全部实测样本之间的光谱相似性，对先验进行残差插值；带宽 0.08、收缩权重 0.5，所有组相同。它是轻量插值代理，不是矿物解混或矿物类别识别；与 P31 的重建指标也不等价。

所有方案都允许作业结束后汇总全部采样结果，包括尚未通过仿真链路交付的数据。其含义是现场作业后的回收处理，不计入作业内在线通信。终局差异只能来自实际采样集合；不能因通信方案多拿到终局数据而获益。

环境只在测量完成后返回隐藏细光谱；策略只持有遥感先验和已观测/交付数据。测量噪声按种子、节点、位置固定，不随事件顺序改变。计算期间收到的信息下次决策才消费；同一时刻事件依 SimPy 固定插入顺序处理，零时延也不会向已经开始的决策追溯注入数据。

结果保留所有种子。先报告效应和描述性种子自举区间，不把区间跨零或不跨零自动当作立项结论；尚无应用依据支持实质收益阈值。

## 真实数据接口与当前获取情况

2026-10-20 首轮核查（历史记录；同日后续通过作者仓库取得数据，见上方链接）：

- [JPL 免费数据页](https://aviris.jpl.nasa.gov/data/free_data.html)列出 Cuprite 1997 反射率产品，页面提供旧 FTP 下载地址。
- 原始 FTP 请求在当前环境返回 502；将该地址换为同主机 HTTPS 后返回 404。这不表示原始数据被确认删除。本轮未取得原始文件。
- [UPV/EHU 数据页](https://www.ehu.eus/ccwintco/index.php/Hyperspectral_Remote_Sensing_Scenes)在当前访问环境返回 403；未绕过访问限制。
- JPL 的公开下载说明已读，但尚未核实具体所获文件的许可、波长、坏波段、空间配准和缩放。**因此没有下载、重分发或声称使用真实 Cuprite 数据。**

外部数据可通过 `--data path/to/scene.npz` 接入。NPZ 必须含：

```python
cube  # H×W×B，预处理为有限的 [0,1] 反射率，不允许 pickle
provenance  # JSON 字符串，必须填写以下字段
{
    "kind": "observed_airborne_proxy",
    "source_url": "...",
    "license_or_access_terms": "...",
    "preprocessing": "波段选择、缩放、裁剪、配准和缺失值处理的完整说明"
}
```

加载器只验证形状、值域、元数据字段和文件哈希，不自动验证许可真实性或科学预处理正确性。实际航空像元也仍是地面观测代理；合成降质先验不是另一架传感器的独立实测。建议先准备小区域，避免全影像的成对距离矩阵占用过大内存。
