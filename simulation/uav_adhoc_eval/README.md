# E2-033 independent evaluation interface

`scenarios.json` enumerates 30 nodes, 5/15/25/35/50 m/s and three motion families in compact and sparse settings. It is a design table, not generated trajectories: area, radio range and seeds deliberately remain null until fixed by E1. Formation requires similar velocity vectors; crossing/separation requires opposing or divergent groups; reorganization requires changing relative positions. Report measured pairwise relative speeds and connectivity, not just absolute speed. Geometry uses an explicitly supplied radius as a simplified geometric assumption, not an RF model.

`analyze.py --input normalized.json --output NEW_EMPTY_DIRECTORY` uses an independent **proposed**, not E1, adapter schema: `events` ordered by t in seconds; offered/admitted/delivered use origin, origin_boot, seq, dst, with receiver==dst on delivery and reachable_at_offer boolean on offered. Duplicate events do not create extra packets. Reachable denominator is connectivity at offer, not reachability over the entire delivery window; report this restriction. `neighbor_received` carries observer, peer, generated_at; `aoi_sample` carries observer and peer at sample time. Unknown pairs count separately; age cannot be refreshed by other peers or old samples. Commands use cmd_id, target, and executor for `command_executed`; a gateway ACK alone is not execution. `link` carries a,b,up; open links are right-censored. The input adapter must preserve full identity and time basis.

`geometry.measure(positions, velocities, radius)` reports graph components, ordered reachable pairs and relative velocities for one snapshot. It does not model RF or derive trajectories. The first batch consists of 5/25/50, not a measured UAV specification. Input geometry and traffic, simulation seed, exact source hash, configuration and manifest must accompany future result analysis. Per-node LoRa delivery, coverage and per-neighbor AoI time series need E1's eventual event contract; the supplied AoI CSV keeps pair IDs and null ages. Failure reasons, queue/peer rejection, control airtime, recovery, LoRa occupancy and complete per-node breakdown remain pending E1 event mapping; no invented fields or results.

`curve.py --csv INPUT --x COLUMN --y COLUMN --output NEW.svg` renders a basic numeric trace. Input must represent one series; pair/strategy labels and independent replicate uncertainty must be handled before plotting. Both output directory and SVG must be new; do not point at historical results. Synthetic fixture checks are not simulations, hardware, RF or empirical performance. No default experiment, background process, or engine import is invoked.

Observer and peer identifiers in normalized AoI records must include their respective boot epochs (for example `MAC@boot`); epoch changes create separate series. `link_transitions` counts initial up observations as transitions, so use a complete initial snapshot or account for this when computing changes per second. No automatic alignment across E1 schema versions is performed.
