# M-064 动态自组网主图重构（2026-11-25）

响应17:20用户提出的“只变红不变拓扑、失效边不该永久占图、线型太多”问题。本轮主图方案**取代**前一轮多颜色历史边常驻方案，不再仅换颜色。

## 现在的交互

1. **新鲜**：蓝色实线，只表示近期邻接采样；旧协议TTL仍null，不谎称实时互通。
2. **暂时失效**：琥珀虚线；软超时/未确认最多展示10秒，重复坏报告不能重新续期。此宽限是展示政策，不是捏造无线有效期。
3. **断开不画**：明确上报lost、最新快照移除、未提供采样时间的方向立即隐藏；软失效到期也隐藏。后台仍留存的原始失效方向进折叠历史，不改raw snapshot，不编造被后台移除的历史。

同一对节点合成一条线；两侧新鲜才双箭头，一侧失效但另一侧仍新鲜则保留真实单箭头，不伪造双向，也不因单侧失败断言整对物理永久断开。只有新鲜Wi-Fi邻接参与分组/层次布局，失效线不拉住节点。默认去掉网关采集星形，可选勾“显示网关上行”；LoRa不参与组网连通分组，不当作多跳捷径。选中节点只轻微强调，不把其他新鲜段压暗到看不见。

## 用户例子的实际SVG回归

- 3/4/5互联：三角形、3条合并连接。
- 3–5双方上报lost：该线立即消失，位置重排为**3—4—5**，2条连接，不保留红色三角边。
- 4–5再失效：**3—4 / 独立5**，仅1条连接；5保留可见，另一个连接分组标“暂无新鲜链路”，不等于其LoRa报告也掉线。
- 重连后恢复三角形；新报告顺序/RSSI/计数变化不让不变邻接乱跳。手动/GPS模式保留各自语义，默认清晰布局才自动重排。

布局只是有效邻接的逻辑分组，不代表地理距离或已实测的业务转发路径。观察中断有全局提示，不能从图中隐藏反推物理断网。记录方向/原证据诊断仍在详情，不再变成主图六种线色。
