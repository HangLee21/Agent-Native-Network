# 动态 AD-HOC 前端

双击同目录的 START_ADHOC_STUDIO.cmd。Linux 可运行 `sh deploy/mobile_gateway/START_ADHOC_STUDIO.sh`。启动器会先检查上游，再打开 http://127.0.0.1:8794/：已有网页服务时同样检查8791无线业务端；缺服务就启动，已有相符服务就复用。

本机Windows台架还会检查热点。热点关闭时按原配置恢复2.4GHz会话，并核实际信道、BSSID和IP与五板已配置值一致；口令和BSSID不打印。原私有配置缺失、凭据或实际信道不符、端口被其它程序占用时停止并保留原进程，在启动日志说明原因，不改板或覆盖原配置。多个双击会串行准备，不启动两套服务。关闭启动器窗口不停止已启动的后台观察服务。

服务就绪但没有板子接入时，页面显示实际等待状态；不会补模拟节点。服务后来退出或热点后来关闭时，再双击同一入口即可检查并恢复。直接打开浏览器地址不执行系统热点恢复。

页面默认看实板。当前五板由 USB 供电，在板内随机等待、选目的并生成业务；电脑只读取无线入口和板上记录，不运行实板业务发生器，不打开串口。节点有没有普通 Wi-Fi 入口、有没有 RF 邻居样本、有没有定位分别显示。没有 RF 样本时不补造连线；无 GPS 仍可看节点和拓扑布局。

勾选 fake_GPS 后，位置来自 E2 的模拟提供器，按实际节点身份产生连续轨迹，明确标为模拟。它只改变展示坐标，不注入板子，不决定无线边。取消勾选即回到未知定位。

软件演示由明确的“开始 / 重播”按钮启动，独立使用 8795。E2 的 fake_agent_function 与 fake_GPS_function 实际运行，传输是标明 host_model 的软件模型。过程包含节点陆续加入、听到邻居、双向确认、链路失效、节点离开重入和观测网关重连。每次新目录、120 秒自动停止；“停止演示”会停止该次全部软件子进程。演示不发包到五块实板，不把模拟结果混入现场会话。重新选择实板即可回到无线观测。

板上记录是抽样读取：显示已导出的原身份和原载荷，跳过与 RAM 覆盖数保留。源接纳、沿途提交和目的接收分别显示，界面不把抽样计数当完整交付率。

高级启动：

```text
python -X utf8 -m tools.mobile_gateway.studio --output simulation/outputs/H-016/新的目录 --stop-file simulation/outputs/H-016/新的目录/STOP
```

原始读取与维护回复在观察目录的 observations.jsonl；启动身份在 PROCESS.json；演示子目录含各 node/agent/model 日志。双击启动器的每次检查记录在新建的H-016/startup-*目录，RESULT.json列本轮启动的进程与各自stop_file；重复启动不另建服务。停止本轮后台服务可创建它对应的stop_file，前台高级命令仍用Ctrl+C。停止观察不会停止板上发生器。8790旧地图与8767历史台架图保持独立。
