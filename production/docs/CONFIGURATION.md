# 节点配置

模板为 `production/config/fleet.example.json`；复制到 `production/local/fleet.json` 后按现场实际修改。`schema_version` 为 1；`nodes` 中每项 `node_id` 为正整数，`mac` 为完整六字节地址。编号和 MAC 各自不得重复；配置请使用小写 MAC，烧录入口当前要求规范小写，页面会在比较前归一化大小写。支持 1、26、27、100 等编号，不以字母表长度为限。未知或未登记 MAC 显示 `UNSET` 与尾码，不以尾码替代实际身份。配置名称只影响显示，不能更改报文中 MAC/boot/seq。

`gateway.eui` 是预期网关 EUI，`candidate_hosts` 为候选地址，`udp_port` 为 1680；`services` 为拓扑和工作台端口；`release_manifest` 为相对配置文件所在目录的发布清单路径。只有连接真实服务并通过身份核验后才能判断网关状态。端口冲突或数据源不可用时应明确显示。不要放凭据。

界面从同源 `/api/v1/fleet` 自动读取启动器选用的同一份配置；生产 Studio 已提供该接口并合并启动器选中的 fleet 与设备注册表；真实 Studio 与页面已完成离线联调。配置未提供、格式错误、版本错误、重复编号或重复 MAC 时，界面清空标签映射并提示配置不可用，并在可见且观测运行时自动重试；不猜设备编号。默认现场操作不选择配置文件。配置分配与设备 NVS 写入、读回由维护人员负责，页面显示不等于写板成功。
