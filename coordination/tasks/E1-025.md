# E1-025 板上自主多跳

状态 review。主卡 [M-029](M-029.md) 为算法及验收依据。

实现、测量、构建可刷的自主路由模式。先交帧/串口契约与计时/内存界限，再交固件；按主卡定序和维护规则，不直接复用112B旧头。

写入范围 firmware/mid_baseline/ 与 tools/mid_baseline/edge_profiles/、本卡及 simulation/outputs/E1-025/ 与 .local/mid/E1-025/ 新目录。实际源码按既有同角色范围接续，不覆盖原产物。依赖直接交接，回填证据、尚未验证的条件和进程状态。

先交核心合同：独立入口`firmware/mid_baseline/autonomous/`，`source_route.h/c`为同一板端/host核心。SR01固定60字节头+0..160字节载荷，最多5节点4跳（完整布局及规则将附INTERFACE.md）；RREQ/RREP/DATA/ERROR四类，复用M027 ND01双向邻居但不复用旧112B ANN头。W=200ms，从首有效RREP起算；绝对deadline1500ms；半开接收窗口，时刻到期先结算再处理新回复。最少跳/完整MAC路径字节序；同候选两个到达顺序都选A-B-C。缓存10s、首跳boot绑定；路已绑定业务不改写、交付未知不重发。8邻居/8缓存/8待发/4轮/每轮16候选/32请求路径副本记录/12发队列/32事件/64目的去重，帧队列250ms过期；sizeof(sr_node)=17696（host ABI，ESP另测）。不同有用RREQ完整路径副本可转发，非只留首到。

串口计划冻结：`route_config {nonce,group,channel,autostart}`只写本板模式组/信道到NVS；`route_start/route_clear`、`routes`本地只读；沿用send(dst,payload_hex)/rx_local原始身份字节及neighbors/neighbor/probe，模式autonomous。台架`link_filter {allow:[MAC...]}`只限制本机逐帧可听/可发关系（运行期、非持久，空allow隔离，clear:true恢复），不提供远端路径或答案；过滤影响HELLO及所有数据/控制，H需清楚标逻辑拓扑。旧MID/edge/discovery独立入口与包均保留。

02-core已实际通过synthetic host：相同两候选顺序互换均A-B-C，5同核节点实际洪泛产生A-B-C/A-D-C回复；同目的两个待发合并一轮，交付2条160B；撤B相关边后新包经D交付；再断D后1500ms无路并清待发。全场控制+数据出队18帧，3/4交付（末条人为不可达）；4跳220B完整帧、重复目的去重、防环/前一跳错误、已绑定下一跳boot变化拒发也通过。不是RF或Ubuntu证据。01首次-Werror编译失败保留，未修改旧结果。
